## 🚀 使用方法

### 1. 初始化知识库
```bash
cd knowledge-base
python3 scripts/main.py init --create-examples
```

### 2. 同步知识到向量数据库
```bash
# 增量同步（推荐）
python3 scripts/main.py sync

# 全量同步
python3 scripts/main.py sync --full
```

### 3. 搜索知识
```bash
python3 scripts/main.py search "彪哥战法核心原则"
```

### 4. 查看状态
```bash
python3 scripts/main.py status
```
