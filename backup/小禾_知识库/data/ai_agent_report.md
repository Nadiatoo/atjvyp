## 六、风险提示

1. **技术不确定性**：AI Agent技术路线仍在快速演进，商业化节奏可能低于预期
2. **竞争加剧**：科技巨头纷纷布局Agent，中小公司可能面临挤压
3. **政策风险**：智能体安全监管政策可能趋严，影响产品部署节奏
4. **估值风险**：概念股短期涨幅较大，存在回调风险
5. **业绩兑现**：多数公司Agent业务仍处早期，业绩贡献有限

## 七、核心结论

**短期催化**：DeepSeek Agent产品发布 + 阿里Qwen3.7-Max + 智谱GLM-5V + 三部门政策联合催化，AI Agent产业链关注度处于历史高位。

**三条主线**：
1. **算力先行**：AI Agent对推理算力的需求比传统大模型更高（实时交互+多步推理），持续利好AI芯片（海光信息/寒武纪）、AI服务器（浪潮信息/中科曙光）、光模块（中际旭创/新易盛）
2. **平台为王**：智能体开发平台/工具链是产业生态核心，中科创达、用友网络、科大讯飞、昆仑万维有先发优势
3. **应用落地**：工业（中控技术）、金融（广电运通/宇信科技）、办公（金山办公）、安全（深信服/启明星辰）是最快落地方向

**重点关注组合（核心标的）**：
- 算力层：海光信息(688041)、中科曙光(603019)、中际旭创(300308)
- 平台层：用友网络(600588)、中科创达(300496)、科大讯飞(002230)
- 应用层：中控技术(688777)、金山办公(688111)、深信服(300454)、昆仑万维(300033)
