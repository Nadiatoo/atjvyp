# 知识管理标准化流程（小禾SOP）

> 版本：v1.0 | 建立日期：2026-05-20
> 用途：所有学习资料的标准化拆解→入库流程

---

## 流程概览

```
接收资料 → 独立拆解 → 结构化提取 → 入库归档 → 关联标记 → 完成
  ①          ②           ③           ④         ⑤        ⑥
```

---

## ① 接收资料

| 来源类型 | 处理方式 |
|---------|---------|
| PDF文档 | 用pymupdf提取文本全文 |
| 网页链接 | 浏览器打开或web_extract |
| 图片截图 | 用qwen-vision读图 |
| 公众号文章 | 复制内容或直接读取 |
| 用户描述 | 记录原始表述 |

**输出**：原始内容缓存到临时文件

---

## ② 独立拆解

**铁律**：不套任何框架，不强行关联已有主线。先理解作者说了什么。

拆解角度：
- **事件**：发生了什么（时间、主体、地点）
- **核心逻辑**：作者认为为什么发生
- **关键数据**：量化信息（数字、比例、趋势）
- **关键公司/标的**：提到了谁
- **后续跟踪点**：哪些变量值得继续看

**检查清单**：
- [ ] 是否客观还原了原文逻辑？（不是我的解读，是作者的逻辑）
- [ ] 关键数据是否已提取？（数字、百分比、时间节点）
- [ ] 是否标注了信息源？
- [ ] 是否识别了原文未覆盖的盲点？

**输出**：结构化拆解笔记（markdown）

---

## ③ 结构化提取

将拆解笔记转为可入库的结构化字段：

```json
{
  "source_type": "研报/公众号/新闻/用户分享",
  "source_name": "来源名称",
  "title": "标题",
  "received_date": "2026-05-20",
  "topics": ["光通信", "光纤", "机器人"],
  "companies": [
    {"name": "亨通光电", "code": "600487", "relevance": "核心标的"},
    {"name": "烽火通信", "code": "600498", "relevance": "核心标的"}
  ],
  "key_data_points": [
    {"metric": "光纤需求占比", "value": "30%", "year": "2027E", "source": "CRU"}
  ],
  "key_events": ["深交所受理乐聚智能IPO"],
  "original_file": "路径/文件名"
}
```

---

## ④ 入库归档

| 内容类型 | 存储位置 | 说明 |
|---------|---------|------|
| 拆解笔记（长文本） | `daily_brief/` 或 `analysis/` | 人类可读的markdown |
| 结构化数据（字段） | DB中相应的表 | 机器可查 |
| 原始文件（PDF/图片） | `archives/` | 原始材料留存 |

文件命名规范：
```
YYYY-MM-DD_类别_简述.md
示例：2026-05-20_daily-brief_光通信光纤.md
示例：2026-05-20_research_乐聚机器人IPO.md
```

---

## ⑤ 关联标记

入库后，将新知识与已有知识建立链接：
- 关联已有题材（themes表）
- 关联已有公司（companies表）
- 关联已有文章（articles表）

**不需要强行关联**。如果新知识不属于已有任何题材，说明题材需要扩展。

---

## ⑥ 完成标记

- 更新知识库状态
- 如涉及代码/自动化需求 → 转给小猪
- 如涉及分析结论 → 在下次对话中可用
