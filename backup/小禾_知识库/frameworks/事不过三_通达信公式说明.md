# 事不过三 · 通达信选股公式

> 基于真如铁「事不过三」压力突破形态
> 参考个股：世嘉科技（002796）2025年7-9月走势

---

## 一、公式源码

```
{事不过三·突破形态选股公式}
{参数定义，可在通达信中调整}

N1 := 60;    {回看天数}
N2 := 5;     {均量周期}
N3 := 1.5;   {放量倍数}

{=== 均线 ===}
MA5  := MA(CLOSE, 5);
MA10 := MA(CLOSE, 10);
MA20 := MA(CLOSE, 20);
MA60 := MA(CLOSE, 60);

{=== 成交量 ===}
VOL5  := MA(VOL, N2);
VOL10 := MA(VOL, 10);
VOL_BOOM := VOL > VOL5 * N3;           {放量: 当前量 > 5日均量*1.5}

{=== KDJ (9,3,3) ===}
RSV := (CLOSE - LLV(LOW, 9)) / (HHV(HIGH, 9) - LLV(LOW, 9)) * 100;
K := SMA(RSV, 3, 1);
D := SMA(K, 3, 1);
KDJ_GOLD := CROSS(K, D);               {K上穿D=金叉}
KDJ_LONG := K > D AND K > REF(K, 1);   {多头向上}

{=== MACD (12,26,9) ===}
DIF := EMA(CLOSE, 12) - EMA(CLOSE, 26);
DEA := EMA(DIF, 9);
MACD := 2 * (DIF - DEA);
MACD_GOLD := CROSS(DIF, DEA);          {DIF上穿DEA=金叉}
MACD_EXPAND := MACD > REF(MACD, 1);    {红柱放大}

{=== 压力位与突破计数 ===}
{取10~60天前的历史最高价作为固定压力位（排除近期新高）}
RES := REF(HHV(HIGH, N1-N2), N2);

{统计60日内收盘价进入压力位±3%的次数}
IN_ZONE := CLOSE >= RES * 0.97 AND CLOSE <= RES * 1.03;
TOUCH_COUNT := COUNT(IN_ZONE, N1);

{平台确认：除今天外至少还有1根K线触碰过压力位}
PLATFORM := COUNT(IN_ZONE, N1) >= 2;

{当前bar正在突破}
BREAKING := CLOSE > RES * 0.97 AND CLOSE <= RES * 1.05;

{=== 趋势条件 ===}
TREND_UP := CLOSE > MA60;              {股价在60线上方}
MA_BULL := MA5 > MA10 AND MA10 > MA20; {均线多头排列}

{=== 综合选股信号 ===}
SELECT := VOL_BOOM                  {放量}
          AND KDJ_LONG              {KDJ多头}
          AND MACD_EXPAND           {MACD红柱放大}
          AND TOUCH_COUNT >= 3      {60日内至少3次触碰压力区}
          AND BREAKOUT              {当前在压力区附近}
          AND TREND_UP              {趋势向上}
          AND CLOSE > OPEN;         {收阳}

SELECT;
```

## 二、导入方法

1. 打开**通达信** → 功能 → 公式系统 → 公式管理器
2. 点击**条件选股公式** → 新建
3. 公式名称：`事不过三突破`
4. 将上方源码粘贴进去 → 保存
5. 使用：`.905` 或 功能 → 选股器 → 条件选股 → 选择「事不过三突破」

---

## 三、参数说明

| 参数 | 默认值 | 含义 | 调整建议 |
|------|:----:|------|------|
| N1 回看天数 | 60 | 压力位取60日最高，触碰计数范围 | 牛市长些(90)，熊市短些(40) |
| N2 均量周期 | 5 | 放量对比的均量周期 | 可改10，要求放量更显著 |
| N3 放量倍数 | 1.5 | 成交量>N日均量*N3 | 1.2=宽松，2.0=严格 |

---

## 四、信号解读

公式出信号后需人工复核：

| 检查项 | 标准 |
|------|------|
| 压力位形态 | 肉眼确认60日最高价确实是前期横盘压力位（不是单日尖峰） |
| 三次触碰 | 在K线图上明显看到3次上攻压力位的痕迹 |
| 缩量回调 | 前两次触碰后缩量回调（不是暴跌） |
| 放量突破 | 第三次触碰时明显放量收阳 |

---

## 五、使用建议

- **大盘环境**：震荡市或温和上升市使用，单边暴跌禁用
- **选股时间**：每天收盘后用（15:00后），公式基于日线数据
- **仓位**：初次建仓≤3成，突破确认后加仓
- **止损**：买入当日最低价下方2%
