# Day 0 板块爆发评估 · 首板日识别框架

> 2026-05-21 光学光电案例精炼。板块爆发第一天（全部首板）时，如何区分"真主线起点"与"一日游"？

## 核心矛盾

板块爆发日通常全部是首板（Day 0），此时没有梯队可验证。但这是观察窗口——**春播窗口本身就在Day 0打开**。关键是：Day 0的哪些信号说明这个板块有持续力？

## 评估五维框架

### ① 中军参与度（最重要信号）

| 中军信号 | 强度 | 案例 |
|:--------|:----:|:----|
| 超级中军（>1000亿）涨停封板 | ⭐⭐⭐ | 京东方A(1770亿)封板85亿 |
| 中军（500-1000亿）涨停封板 | ⭐⭐ | TCL科技(937亿)封板11亿 |
| 重量级参与但没封板（+8-9%） | ⭐ | 机构认可但犹豫 |
| 小票群板+没大票 | ❌ | 游资行情，一日游概率大 |

**案例解读：** 5/21光学光电11只涨停中，京东方A+85亿封板+TCL科技+11亿封板=中军参与度极高，这不是游资能做的量级。

### ② 板块位置（地利）

- ✅ **低位启动**（距60日线-5%~-15%）= 春播窗口条件满足
- ⚠️ **中位震荡**（60日线附近）= 可启动可一日游，观察
- ❌ **高位（近期涨幅>30%）** = 补涨/拉高出货概率大

### ③ 内部结构

| 结构特征 | 持续性评估 |
|:--------|:----------|
| 央企/机构重仓股领涨 | 偏持续（机构不是一日游） |
| 纯游资票（<50亿市值群板） | 偏一日游（量化+游资套利） |
| 中军封板资金>50亿 | 高置信度 |
| 首板炸板率>30% | 低置信度 |

### ④ 和大盘共振（春播四特征①）

- ✅ **板块爆发日大盘涨** = 板块带动市场情绪 → 加分
- ⚠️ **板块涨但大盘跌** = 板块内资金轮动非普涨 → 减分
- ✅ **板块驱动大盘开盘跳空高开** = 最强共振信号

### ⑤ 催化逻辑（人和）

- ✅ **有明确产业逻辑**（涨价/政策/技术突破）→ 人和具备
- ⚠️ **无明确催化** → 纯情绪驱动，持续性低
- ⚠️ **催化清晰但逻辑偏弱**（旧题材翻新）→ 谨慎追高

## Day 0 → Day 1 验证表

| 验证项目 | Day 1达标标准 | 信号强弱 |
|:--------|:------------:|:--------:|
| 至少3只个股晋级2板 | ≥3只 | ⭐⭐⭐ 最硬信号 |
| 板块涨停数扩容 | Day0的50%+（如Day0=11, Day1≥6） | ⭐⭐ |
| 京东方A/TCL/中军继续红盘 | 不暴跌，震荡整理 | ⭐⭐⭐ 中军不倒=板块不倒 |
| 板块内出现新首板补涨 | 有新人加入 | ⭐⭐ |
| 首板占比回落 | ↘ <75% | ⭐ |
| **全部断板（0只2板）** | 🔴 板块效应证伪 | 立即放弃 |

## 评估流程

```
Day 0 看盘发现板块爆发
    ↓
五维扫描：
① 中军参与度（超级中军封板=最强信号）
② 板块位置（低位=地利）
③ 内部结构（机构重仓参与加分）
④ 大盘共振（板块带动大盘加分）
⑤ 催化逻辑（有逻辑=人和）
    ↓
找催化源头：Baidu浏览器搜索 > Sina新闻Feed（Sina已验证返回旧数据）
    ↓
综合评分 → 定性：真主线候选 / 观望待验证 / 一日游
    ↓
Day 1 验证表确认 → 调整仓位和方向
```
