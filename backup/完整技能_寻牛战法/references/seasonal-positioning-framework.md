## 一、总纲：适用范围与前置判断

### 1.1 适用范围

四季框架适用于**任何周期、任何层级**：

| 层级 | 周期长度 | 应用方式 |
|------|---------|---------|
| 🌍 **宏观底色** | 季~年 | 定宏观约束条件（地缘/货币/通胀），为下层定基调 |
| 🏛️ **大盘** | 月~季 | 判断整体市场环境，定总仓位 |
| 📦 **板块** | 周~月 | 判断各板块所处季节，定方向 |
| 📈 **个股** | 天~周 | 龙头+中军的识别与确认 |

### 1.2 分析路径

```
🌍 宏观底色（约束条件）
    ↓
🏛️ 大盘四季定位
    ↓
📦 板块四季定位
    ↓
📈 龙头中军确认
```

> ⚠️ **宏观底色不决定买卖点，但它决定你对大盘四季判断的置信度。**
> 滞胀环境下 → 秋收需要更果断
> 降息窗口预期下 → 夏长可以更大胆
> 地缘风险高企 → 冲击型冰点概率增加，提前防范

### 1.3 宏观底色的四大监测维度

| 维度 | 核心指标 | 数据来源 |
|------|---------|---------|
| 🌍 **地缘格局** | 美伊/中美/俄乌等关键冲突走向 | QVeris新闻舆情 |
| 💰 **全球货币** | 美联储/欧央行/BOJ政策路径，利率预期 | QVeris宏观数据+新闻 |
| 📊 **宏观数据** | CPI/PPI/就业/PMI，中美欧三大经济体 | QVeris macro_china |
| 🔗 **产业链** | 关键商品价格（原油/黄金/芯片/锂等） | QVeris行情数据 |

### 1.4 前置判断：冲击型冰点 vs 内生型冰点

> **核心原则**：四季框架基于市场内生节奏。必须先区分冰点类型，否则框架会失效。

| | 冲击型冰点 | 内生型冰点 |
|--|-----------|-----------|
| **成因** | 外部突发事件（政策突变、地缘冲突、流动性危机） | 市场自身出清（情绪过热后自然降温） |
| **特征** | 快、急、猛，几天内恐慌一次性释放 | 有酝酿过程，有情绪传导时间差 |
| **可预测性** | 不可预测、不重复、无规律 | 可识别、有规律、可重复 |
| **应对方式** | **排除在四季框架外**，单独应对（保存弹药、等局势落地） | **适用四季框架**，是春播的土壤 |
| **恢复特征** | 冲击消退后修复迅速，新主线往往同步诞生 | 恢复周期更长，需逐步磨底 |

**典型案例对照：**
- 1月13日政策降温退潮 → **内生型**（自然降温→试错新周期）
- 3月23日伊朗冲突暴跌 → **冲击型**（外部事件→保存弹药→等局势落地）

## 二、第一层：大盘四季定位

### 2.1 判断数据源

| 指标 | 获取方式 | 用途 |
|------|---------|------|
| 上证指数位置 | QVeris | 趋势方向 |
| 涨跌比 | QVeris-市场宽度 | 情绪温度 |
| 涨停/跌停家数 | QVeris-板块排行 | 短线温度 |
| 连板高度/个数 | 复盘数据 | 接力意愿 |
| 全市场成交额 | 复盘数据 | 资金态度 |
| 20cm涨停数量 | 复盘数据 | 高风险偏好 |
| 新高/新低家数 | QVeris-市场宽度 | 结构健康度 |
| 炸板率 | 复盘数据 | 分歧程度 |

### 2.2 四季判断标准

#### 🌱 春播（买入试探期）

**必要条件（至少满足3条）：**
- [ ] 大盘经历恐慌杀跌后企稳，指数处于相对低位
- [ ] 跌停家数从高点回落（从50+降到个位数）
- [ ] 涨停家数从冰点（30家以下）回升到40-60家
- [ ] 涨跌比修复到1:1以上
- [ ] 连板高度从3板以下回升到4-5板
- [ ] 首板溢价开始为正，打板不被闷杀

**加分信号：**
- 新题材出现，首板批量涌现（10+）
- 前期A杀的龙头开始止跌修复
- 成交温和放量（不要求爆量）

**战法对照：**
> *"无恐慌不开仓"* → 春播必须有恐慌出清在前
> *"倒春寒"* → 春播后常有二次回踩确认，不是真退潮

---

#### ☀️ 夏长（持股/加仓期）

**必要条件（至少满足4条）：**
- [ ] 大盘趋势向上，连续阳线或震荡上行不破关键均线
- [ ] 涨停家数稳定在60-100+家
- [ ] 涨跌比持续偏好（2:1以上）
- [ ] 连板高度在5板以上，有龙头带队
- [ ] 成交量持续活跃（2.5万亿+）
- [ ] 20cm涨停常态化（10+个）
- [ ] 反包模式有效：断板第2-3天给溢价

**加分信号：**
- 主线清晰，板块内有完整的连板梯队
- 中军股（千亿大票）趋势走强
- 新高家数持续>200

**夏长末端预警信号：**
- ⚠️ 成交放量滞涨（量升价不升）
- ⚠️ 龙头开始出现分歧断板后不能快速修复
- ⚠️ 新高家数减少，新低家数增加

**战法对照：**
> *"错过春播则挖掘补涨"* → 夏长中期仍有补涨机会
> *"补涨铁律：位置低=核心"* → 板块高潮日=补涨最佳卖点

---

#### 🍂 秋收（卖出/减仓期）

**必要条件（至少满足3条）：**
- [ ] 大盘触及前高压力位，冲高回落或震荡加剧
- [ ] 涨跌比开始频繁恶化（连续出现1:2以上）
- [ ] 涨停家数从高点回落，跌停开始增加（10+）
- [ ] 连板高度压缩（从7-8板压到4-5板）
- [ ] 高位核心票出现批量跌停（核按钮）
- [ ] 反包模式失效：断板后继续A杀
- [ ] 炸板率高企（40%+）

**秋收卖出节奏：**
```
第一步：跟风板块/后排股先走
第二步：中位趋势股减仓
第三步：核心股观察5日线，破就走
```

**加分信号：**
- 监管出手（异动监管/停牌/问询函）
- 题材轮动加速到日内多个题材，无一持续
- 利好不涨，利空大跌

> ⚠️ **量化时代补丁**：秋收节奏需要前置。以前是"看到分歧再卖"，现在是"高潮当天就要开始卖"。量化把"渐次退潮"变成了"瞬间冰点"。

---

#### 🚨 夏秋过渡混沌期（边界模糊信号集）

> 当大盘同时呈现夏长末段和秋收初段的特征，无法明确归类时。不是"市场不行了"，而是"旧主线死了，新主线还没生出来"。

**混沌确认信号集（满足4条及以上=确认混沌过渡期）：**
- [ ] 前2大主线板块同时崩塌（涨停从8+分别降至≤2和0）
- [ ] 唯一增量板块全部为首板（无2板晋级，板块梯队未建立）
- [ ] 总涨停从70-90+区间骤降至~60（降幅30%+）
- [ ] 首板占比 > 80%
- [ ] 行业分布散乱（TOP1板块≤6只，其余行业≤3只）
- [ ] 高标独立行走（先锋涨停但板块内无跟风，板块无人跟随）
- [ ] 指数严重分化（科创/创业板大涨但主板平盘或微跌）

**混沌期应对策略：**
- 总仓位：轻仓（4-5成），不做重仓
- 方向：聚焦唯一增量板块的持续性（观察次日能否出2板）
- 手法：趋势低吸为主，连板接力观望
- 风控：若增量板块次日也退潮，则全场无主线，可能加速下探

**案例（2026-05-20）：** 元件8→2、电力8→0同时崩塌；半导体3→6全部首板；总涨停90→61；首板83.6%；高标独立但板块无人跟。

#### ❄️ 冬藏（空仓/防守期）

**必要条件（至少满足3条）：**
- [ ] 大盘趋势破位，连阴下跌
- [ ] 涨停家数在30家以下，跌停50+
- [ ] 涨跌比冰点（1:4以上）
- [ ] 连板高度压缩到3板以下
- [ ] 成交量持续萎缩（2万亿以下）
- [ ] 无主线，轮动混乱或全面熄火

**冬藏尾声信号（→春播）：**
- ✅ 最抗跌的板块开始补跌（最后一批多头投降）
- ✅ 跌停家数从峰值回落
- ✅ 资金开始试错首板
- ✅ 成交量极度萎缩后出现温和放量

**战法对照：**
> *"管住手"* → 冬藏就是管住手，不抄底、不补仓
> *"冬季尾声标志：逆势逞强的板块完成补跌"*

## 三、第二层：板块四季定位

### 3.1 核心原则

> **板块四季与大盘四季不必然同步。** 大盘在秋收，不代表所有板块都在秋收。量化时代，多季节并存是常态。

### 3.2 判断维度

| 维度 | 判断方式 |
|------|---------|
| 板块指数位置 | 相对大盘是强（新高）还是弱（破位） |
| 板块内涨停数 | 爆发期（10+）/ 活跃期（5-10）/ 零星（1-4）/ 无 |
| 梯队结构 | 完整（先锋+中军+后排）/ 断层（只有龙头）/ 无 |
| 龙头状态 | 主升中 / 卡异动 / 高位震荡 / 补跌 |
| 催化消息 | 新鲜重磅 / 老消息反复 / 无催化 |
| 与大盘共振 | 共振（同步）/ 抗跌（独立）/ 背离（反向） |

### 3.3 关键前置：行业分类 vs 概念分类

> ⚠️ **常见错误**：用申万行业分类代替市场概念板块来分析。传统行业分类是制造业视角，更新慢；市场炒作的是产业主题视角，动态变化。两者是不同体系。

#### 为什么不能用申万行业直接代替

| 对比项 | 申万行业分类（行业板块） | 同花顺/东方财富分类（概念板块） |
|-------|------------------------|-------------------------------|
| **分类逻辑** | 按产品/服务划分，静态 | 按市场主题/产业链划分，动态更新 |
| **更新速度** | 年度调整，滞后 | 实时跟进新题材、新产业 |
| **成分股** | 固定，边界清晰 | 灵活，随市场认知变化 |
| **举例** | 航天装备Ⅱ只有9只国企 | 商业航天包含国企+民企+产业链上下游客，数量远多于9只 |
| **适用场景** | 长期基本面/机构配置 | **短线/题材炒作分析** |

#### 实战中如何选择

| 你的分析目的 | 应该用什么分类 | 原因 |
|------------|--------------|------|
| 判断板块四季定位 | **概念板块** | 市场炒作什么就看什么分类 |
| 识别龙头中军 | **概念板块** | 先锋金螳螂不属于航天装备Ⅱ，属于商业航天概念 |
| 判断产业景气度 | 申万行业 | 机构研究常用，基本面分析适用 |
| 复盘总结周期 | **概念板块** | 因为市场就是按概念炒的 |

#### 区分方法

同一个股票可以同时属于多个分类：

```
航发展（航天发展）
  ├── 申万行业：航天装备Ⅱ（传统制造业分类）
  ├── 概念板块：商业航天（市场题材分类）
  ├── 概念板块：航天系（央企集团分类）
  └── 概念板块：军工（行业属性分类）
```

**核心规则：做板块四季分析时，优先使用概念板块分类。** 传统行业分类可以作为基本面参考，但不能代替概念板块来判断市场主线和龙头中军。

#### 回测验证：错误使用申万分类的后果

| 场景 | 用申万分析 | 用概念分析 | 实际结果 |
|------|-----------|-----------|---------|
| 商业航天（1月） | 航天装备Ⅱ只有9只国企，板块效应弱 | 商业航天板块涨幅居前，涨停50+ | ✅ 概念分类正确反映 |
| 太空光伏（1月） | 光伏设备行业 | 太空光伏概念 | ✅ 概念更精准 |
| 国产算力（5月） | 计算机/电子行业，范围太宽 | 国产算力/国产替代概念 | ✅ 概念聚焦核心 |

#### 3.3.1 进阶：概念板块内部的"主场vs客场"——一只股票的多概念身份管理

> **核心问题**：一只股票可以同时属于多个概念板块，但每个板块给它的角色权重完全不同。分析时如果不区分"主场概念"和"客场概念"，会导致逻辑矛盾——同一个股票既可以是板块A的中军，同时被用作板块B的佐证，产生"自相矛盾"的错觉。

**典型案例：易中天（中际旭创+新易盛+天孚通信）的三重概念身份**

| 个股 | 所属概念板块 | 在该板块的角色 | 身份类型 |
|------|------------|--------------|---------|
| 中际旭创 | **光通信/CPO** | 🏛️ **核心中军**（成交最大、逻辑最纯、市值最大） | ✅ **主场** |
| 中际旭创 | 国产算力基础设施 | ❌ 边缘成分股（算力中军是寒武纪/海光，不是光模块） | ⛔ **客场** |
| 中际旭创 | AI硬件 | ✅ 中军 | ✅ 主场 |

**为什么必须区分：**

假设场景——光通信板块大涨（中际旭创+8%），同时国产算力板块退潮：

| 表述方式 | 是否正确 | 为什么 |
|---------|---------|--------|
| "光通信板块走强，中军中际旭创+8%" | ✅ 正确 | 在主场概念里分析 |
| "国产算力还在撑，中际旭创+8%没跌" | ❌ 逻辑错误 | 光模块是国产算力的客场概念，不能作为国产算力还健康的证据 |
| "国产算力退潮，但资金从国产算力中剥离出光通信细分形成独立走强" | ✅ 正确 | 区分了资金切换方向 |

**判断规则：**

1. **一只股票只有一个"主场概念"**——即它的核心逻辑归属、资金共识最强的那个板块
2. **在其他概念板块中，该股票是"客场身份"**——其涨跌不构成该板块的核心判断依据
3. **出现"某票在板块A涨，但在板块B的角色中被引用"时** → 先check这个票在板块B是主场还是客场
   - 主场 → 有效证据
   - 客场 → 不能作为该板块的判断依据（可能只是资金联动/溢出效应）

**历史对标：**

| 股票 | 主场概念 | 在主场是 | 客场概念举例 | 在客场是 |
|------|---------|---------|------------|---------|
| 航发展 | **商业航天** | 总龙1 | 航天系 | 成分股 |
| 中国卫星 | **商业航天** | 中军 | 军工 | 中军（同样有主场地位，跨板块中军可共存） |
| 中际旭创 | **光通信/CPO** | 核心中军 | 国产算力 | 边缘成分股 |
| 寒武纪 | **国产算力** | 核心中军/总龙1 | AI芯片 | 中军 |
| 华电辽能 | **电力** | 连板先锋 | 绿电 | 成分股 |

> ⚠️ **实地原则**：分析板块四季时，只引用该板块**主场股票**的表现作为判断依据。引用客场股票的数据会导致框架逻辑自相矛盾。

### 3.4 四季判断速查

| 季节 | 板块指数 | 涨停数量 | 梯队 | 龙头状态 | 策略 |
|------|---------|---------|------|---------|------|
| 🌱 春播 | 低位企稳或刚启动 | 3-8个首板 | 萌芽 | 首板试探 | 观察，等2板确认 |
| ☀️ 夏长 | 趋势上行，新高不断 | 10-30+ | 完整梯队 | 主升加速 | 核心持股，补涨挖掘 |
| 🍂 秋收 | 高位震荡，开始滞涨 | 从高点回落 | 断层，后排先掉 | 卡异动/分歧加大 | 去弱留强，渐次撤退 |
| ❄️ 冬藏 | 破位下行 | 0-3个，多为反抽 | 无梯队 | 补跌或A杀 | 回避，等出清 |

### 3.5 春播阶段——如何判断新主线

> 参考：《如何尽早判断出新一轮市场主线》——庄稼人战法核心方法论

#### 主线四大特征

**特征①：带动大盘共振反弹（必要条件）**
- 春播日，板块能有效带动大盘一起反弹
- 独涨不是主线，没有号召力的板块不与大盘共振
- ⚠️ 误区：春播日第一个反弹的不一定是主线；第一个共振的也不一定是主线

**特征②：抗倒春寒**
- 发生分歧（倒春寒）时，主线板块表现有韧劲
- 回调幅度小于大盘，修复速度快于其他板块

**特征③：地利人和加分**
- **地利**：位置低（前期无获利盘，多方力量容易占据上风）
- **人和**：产业逻辑强（具有产业预期差，容易共振更多资金）
- 两者兼备 → 主线概率极高

**特征④：板块阵型完整**
- **🚀 先锋**：连板人气股，小市值，聚焦全场目光
- **🏛️ 中军**：逻辑最纯正的大体量公司，大资金主战场
- **🚶 后排**：补涨跟随，前排涨停后批量跟风
- ✅ 合格阵型 = 阶梯式进攻（先锋打开空间 → 中军稳定军心 → 后排跟进）
- ❌ 不合格 = 一窝蜂涨停，无中军坐镇 → 一波流，一触即溃

#### 主线判断流程

```
① 春播日板块启动
    ↓
② 是否带动大盘共振？     → 否 → 排除（非主线）
    ↓ 是
③ 板块阵型是否完整？     → 先锋+中军+后排
    ↓ 是
④ 是否具备地利人和？     → 位置低+产业逻辑强
    ↓ 是
⑤ 倒春寒日是否抗跌？     → 修复速度快于大盘
    ↓ 是
✅ 主线确认概率高
```

#### 验证结论（基于80+份复盘数据回测）

| 特征 | 角色 | 验证结果 |
|------|------|---------|
| **特征① 带动大盘共振** | **硬性门槛** | ✅ 不满足的板块100%不是主线（如太空光伏） |
| **特征④ 抗倒春寒** | **充分条件** | ✅ 前3条符合但扛不住分歧的，都是伪主线（如贵金属有色） |
| 特征② 阵型完整 | 必要条件 | ✅ 阵型不完整的板块走不远 |
| 特征③ 地利人和 | 加分项 | ✅ 没有加分项也能成主线（纯情绪主线），但有加分项的走更远 |

**核心决策规则：**
1. 特征①不满足 → **直接排除**，不管其他特征多好（节省大量时间精力）
2. 特征①+②+③满足 → **进入候选池**
3. 特征④（抗倒春寒）验证通过 → **主线确认**
4. 扛不住分歧的 → **伪主线**，即使前3条都符合也要放弃

### 3.6 分歧与修复的识别

```
强分歧：批量跌停（5+），龙头断板炸板，修复失败
弱分歧：部分掉队，龙头仍强，次日给修复
修复：昨日大跌票今天反包，梯队恢复
修复失败：修复只持续半天，尾盘再次走弱
反包技能卡：第一次反包有效，第二次被量化反收割，效力递减
```

## 六、关键细节（进阶判断标准）

### 6.1 倒春寒 vs 真退潮

> 这是春播后遇到的第一个核心判断。分歧来了——是春播失败（真退潮）还是正常回踩（倒春寒）？判断错了，方向全反。

#### 倒春寒的特征（正常，春播继续有效）

- **跌幅小**：板块/大盘回调幅度明显小于之前恐慌阶段的跌幅
- **缩量**：回调时缩量，说明不是恐慌出逃，只是部分获利盘兑现
- **龙头抗跌**：板块的先锋或中军横盘或微跌，没有批量跌停
- **修复快**：1-2天内给出修复，或盘中即完成V转
- **其他板块配合**：有新的补涨分支出现，板块内部高低切

**典型案例对照（来自复盘）：**

| 场景 | 倒春寒判断依据 | 结论 |
|------|--------------|------|
| 1.5复盘后1.6的分歧 | 当日即修复，前排核心票晋级率极高 | ✅ 倒春寒 → 继续夏长 |
| 1.8→1.12商业航天 | 缩量回调→放量反包新高，核心票不破5日线 | ✅ 倒春寒 → 加速主升 |
| 5.6高潮→5.7分歧 | 涨跌比仍健康（1372:812），新高家数不减 | ✅ 倒春寒 → 夏长延续 |

#### 真退潮的特征（春播失败，需重新评估）

- **跌幅大**：板块跌幅显著，核心票跌停
- **放量下跌**：说明资金恐慌出逃，不是正常的洗盘换手
- **龙头崩盘**：先锋连板股A杀，中军破位
- **修复失败**：反弹只持续半天，尾盘再次跳水
- **无承接**：跌停板封单大，撬板后继续按死

**典型案例对照：**

| 场景 | 真退潮判断依据 | 结论 |
|------|--------------|------|
| 1.13商业航天退潮 | 批量跌停49个，炸板率60%，连板从12板→6板 | ✅ 真退潮 → 秋收确认 |
| 3.17大盘破位 | 4500只绿盘，连板高度崩塌，反包模式失效 | ✅ 真退潮 → 冬藏开启 |

#### 决策流程图

```
春播后遇到分歧
     ↓
龙头是否跌停？     → 是 → ？其他核心票是否跟随？
     ↓ 否                            ↓
成交量缩量还是放量？ → 放量 → 修复尝试是否成功？
     ↓ 缩量                         ↓失败
板块内有无新补涨分支？ → 无 → 整体亏钱效应是否扩散？
     ↓ 有                         ↓是
✅ 倒春寒 → 低吸加仓           ❌ 真退潮 → 减仓/离场
```

### 6.2 板块阵型健康度跟踪

> 一个板块的阵型状态，是判断它处于四季哪个阶段的核心依据。

#### 三大角色的识别标准

| 角色 | 市值 | 涨幅特征 | 成交量 | 辨识度 |
|------|------|---------|-------|-------|
| 🚀 **先锋** | 小（<100亿） | 连板居多，涨幅最快 | 换手率高 | 最高，全场焦点 |
| 🏛️ **中军** | 大（500亿+） | 趋势为主，涨幅中等 | 成交额全市场前列 | 机构认可度 |
| 🚶 **后排** | 不定 | 跟风补涨，首板为主 | 随板块放量 | 弱 |

#### 阵型健康度的四个阶段

**阶段①：阵型形成期（🌱春播→夏长初）**
```
特征：
- 先锋首次连板打开空间（2-3板）
- 中军开始放量走趋势，但未加速
- 后排零星跟风首板

健康信号：先锋晋级时中军不砸盘，后排有跟风
危险信号：先锋独涨，中军不动，后排无响应 → 一波流概率大
```

**阶段②：阵型稳固期（☀️夏长中段）**
```
特征：
- 先锋高位震荡或卡异动，辨识度已建立
- 中军稳步推进，成交额持续放大
- 后排批量补涨，板块涨停扩散

健康信号：三个层次都有票活跃，梯队完整
危险信号：先锋断板后无新接力，中军开始放量滞涨
```

**阶段③：阵型松动期（🍂秋收初）**
```
特征：
- 先锋断板后无法快速修复，或直接A杀
- 中军冲高回落，量能萎缩
- 后排先掉队，涨停数从高点回落

核心判断：如果中军还能稳住，只是后排退潮 → 弱分歧（还可观察）
          如果中军也开始破位 → 确认秋收
```

**阶段④：阵型瓦解期（❄️冬藏）**
```
特征：
- 先锋补跌
- 中军破位
- 后排无涨停
- 板块指数破位
```

#### 阵型速查表

| 状态 | 先锋 | 中军 | 后排 | 结论 |
|------|------|------|------|------|
| 🟢 健康 | 连板中或高位震荡 | 趋势向上 | 有跟风涨停 | 夏长继续 |
| 🟡 预警 | 断板但未A杀 | 趋势未破 | 涨停减少 | 弱分歧，观察 |
| 🟠 风险 | 断板后大跌 | 冲高回落 | 无跟风 | 秋收信号 |
| 🔴 瓦解 | 补跌 | 破位 | 无涨停 | 冬藏确认 |

### 6.3 个股层面：龙头与中军的确认

> 龙头和中军是一轮周期中**赚钱效应最高、确定性最强**的标的。龙头打空间、定情绪；中军稳军心、定趋势。两者确认了，板块分析的落地就有了锚。

#### 一、龙头的两种类型（重要区分）

**框架验证发现：连板先锋和趋势总龙需要用不同的方式确认。** 不能混为一谈。

| 对比维度 | 🚀 **连板先锋** | 🏆 **趋势总龙（龙1）** |
|---------|---------------|---------------------|
| 典型标的 | 雷科、白银有色、华电辽能、利通电子 | 航发展、寒武纪 |
| 走势特征 | 连板爆发，短期涨幅大 | 趋势推进，贯穿整个周期 |
| 确认方式 | 3天确认法（连板/反包） | 观察是否每个阶段都创新高 |
| 持有策略 | 断板不修复就走 | 不破5日线不卖 |
| 最大风险 | A杀 | 阴跌 |
| 对板块的意义 | 打空间、定情绪 | 定趋势、定生死 |

**两者关系：** 一轮大周期中，可以同时存在趋势总龙（贯穿）和多个连板先锋（阶段轮动）。如商业航天周期中，航发展是总龙1贯穿1-2月，而连板先锋从雷科→神剑→银河逐个轮动。**趋势总龙的赚钱效应和确定性往往高于连板先锋。**

#### 二、连板先锋的确认标准（3天确认法）

**龙头不是"最先涨停的那个"，而是"在关键节点扛住分歧的那个"。**

| 确认维度 | 标准 | 你的复盘验证 |
|---------|------|------------|
| **⏱ 时间优先** | 板块爆发日，前10-30分钟内主动领涨涨停 | "前10分钟主动领涨的辨识度标的"（1.8复盘） |
| **📏 高度优先** | 连板高度板块内最高，率先打出空间 | 航发展、华电辽能、白银有色 |
| **🛡️ 分歧抗跌** | 板块分歧日跌幅最小，或断板后快速修复 | "能扛住分歧的才是真龙头" |
| **🔁 反包能力** | 断板后第2-3天给反包，有反包技能卡护身 | "辨识度高的票，断板第2-3天反包概率大"（1.29） |
| **👁️ 带动性** | 它一涨停，板块内其他票跟风 | "鲁信拉板间接带动通宇转强上板"（1.7） |
| **📢 辨识度** | 全市场讨论焦点，各路资金关注 | "众城和流金，明天就看他们是否能晋级"（1.12） |

**龙头确认流程：**

```
板块爆发日
    ↓
最先涨停的2-3个票进入候选
    ↓
第2天（分歧日）观察：
  ┣━ 继续涨停 → 初步确认为龙头
  ┣━ 断板但盘中给修复 → 仍有龙头相
  ┗━ 断板后A杀 → 排除
    ↓
第3天（二次确认）：
  ┣━ 反包涨停 → 龙头确认 ✅
  ┗━ 继续走弱 → 龙头地位被卡位
```

**⚠️ 常见误区：**
- 第一个涨停的不一定是真龙头（1.12格利尔竞价不及预期被卡位）
- 连板最高的不一定是最核心的（航发展不是连板最高，但它是总龙1）
- 龙头可以不止一个——趋势龙头和连板龙头可以并存

#### 三、中军的确认标准

> 中军是板块的"定海神针"——大资金的主战场，板块趋势的核心锚。

| 确认维度 | 标准 | 你的复盘验证 |
|---------|------|------------|
| **💰 市值** | 500亿+，最好是千亿级别 | "千亿大票3-5连板的好几个"（1.12） |
| **🎯 逻辑纯正度** | 主营业务与题材高度匹配，非蹭概念 | "卫星卫通等大中军龙头地位不可动摇"（1.8） |
| **📊 成交额** | 板块内成交额最大或前列，全市场TOP级别 | 易中天成交超200亿 |
| **📈 走势特征** | 趋势为主，小阳/中阳推进，非连板急拉 | 机构风格，走走停停 |
| **🏦 资金属性** | 机构+游资合力，龙虎榜有机构席位 | "机构回补科技大票" |
| **🔄 周期穿越** | 板块分歧时中军承接最强，决定板块生死 | "如果中军还能稳住→弱分歧" |

**中军 vs 龙头的核心区别：**

| 对比维度 | 🚀 龙头（先锋） | 🏛️ 中军 |
|---------|---------------|---------|
| 市值 | 小（<100亿） | 大（500亿+，甚至千亿） |
| 涨幅方式 | 连板爆发 | 趋势推进 |
| 资金属性 | 游资+量化+散户 | 机构+大游资 |
| 最大风险 | A杀 | 阴跌 |
| 谁在主导 | 情绪资金 | 配置资金 |
| 与板块关系 | 打空间、定情绪 | 稳军心、定趋势 |
| 卖出信号 | 断板后不能修复 | 放量破5日线 |

#### 四、龙头与中军的互动关系

这是判断板块所处阶段的核心观察点：

**▎阵型往上走（健康）**
```
龙头涨停 → 中军稳步跟涨 → 后排补涨
           ↓
龙头分歧 → 中军不跌 → 后排虽有掉队但龙头次日修复
           ↓
板块继续推进
```

**▎阵型往下走（风险）**
```
龙头分歧 → 中军下跌 → 后排批量跌停
           ↓
龙头试图修复 → 中军不跟 → 修复失败
           ↓
板块确认退潮
```

**关键判断规则：**
1. **龙头倒，中军不倒** → 弱分歧，还有机会（倒春寒）
2. **中军倒，龙头再强也没用** → 真退潮，板块确认结束
3. **中军加速** → 往往是板块高潮信号（补涨铁律验证）
4. **中军破位** → 板块确认冬藏，无需再看

#### 八、连板先锋7维验证系统（基于历史行情的深度提炼）

> 从商业航天（雷科/神剑）、有色（白银有色）、电力（华电辽能）、算力（利通电子）4轮主线行情中，提炼出7维筛选标准。**核心原则：龙头不是"最先涨停的那个"，而是"在关键节点扛住分歧的那个"**。首日封板只是入场券，真正的验证从第2天开始。

#### 九、趋势总龙4维确认系统

与连板先锋不同，趋势总龙（如航发展、寒武纪）不靠连板打空间，而是靠趋势推进贯穿整个周期。

| # | 特征 | 历史案例 | 量化标准 |
|---|------|---------|---------|
| ① **贯穿全周期** | 航发展贯穿商业航天12月-1月，每个小阶段都创新高；寒武纪贯穿国产算力4-5月周期 | 板块持续多久它就涨多久。板块出现分歧时它不破位。 |
| ② **不连板、趋势推进** | 航发展全是小阳/中阳，无连板急拉；寒武纪也是趋势走法 | 单日涨幅通常3-8%，不出现连续涨停。 |
| ③ **5日线是生命线** | 航发展整个周期不破5日线；一旦跌破=趋势结束信号 | **破5日线=减仓，连续2日站不回=清仓** |
| ④ **成交额持续前列** | 航发展成交持续50-100亿；寒武纪成交50-80亿 | 成交额在全市场TOP100，且不随板块高潮而骤降 |

**趋势总龙 vs 连板先锋的配合关系：**

在一轮大周期中，两者通常并存：
- **趋势总龙贯穿全过程**，提供"这个板块还在"的定力锚
- **连板先锋阶段性轮动**，从雷科→神剑→银河逐个更换，每个阶段打不同空间
- **趋势总龙的赚钱效应和确定性往往高于连板先锋**（框架验证报告结论）

**当前趋势总龙候选（5月）：** 寒武纪、海光信息（国产算力方向，秋收中需观察）；中际旭创（光通信方向，夏长中）

#### 十、不同季节下的龙头/中军策略

> "卖在高潮一致"是战法的核心规则，但高潮什么时候确认？不能等看到跌停再卖。

#### 三层卖出信号

**第一层：预警信号（开始减仓）**

出现任意1条即触发：
- [ ] 板块成交额创近期天量，但涨幅收窄或冲高回落
- [ ] 龙头炸板次数增多，回封越来越勉强
- [ ] 前期A杀的票开始有反抽涨停（往往是补涨尾声信号）
- [ ] 监管异动消息密集出现

**第二层：确认信号（大幅减仓）**

> ⏰ **框架验证发现：预警信号出现后，到确认信号触发，时间窗口约1-2天。** 这是减仓的最后安全期。超过2天还不处理，就会面临批量跌停无法脱身。

出现任意1条即触发：
- [ ] 板块内出现第一个跌停的核心股
- [ ] 先锋断板当日无修复，尾盘封死跌停
- [ ] 中军放量收阴，跌破5日线
- [ ] 一日之内板块从涨停潮变成跌停潮

**第三层：清仓信号（全部离场）**

出现任意1条即触发：
- [ ] 板块指数跌破10日线
- [ ] 中军连续2日放量下跌，无法修复
- [ ] 监管出台针对板块的实质性降温措施
- [ ] 大盘同步破位，形成共振下跌

#### 卖出的节奏

```
高潮日（预警阶段）
    ↓ 减仓后排，留核心
第一次分歧（确认阶段）
    ↓ 减仓中位，核心降仓
全面退潮（清仓阶段）
    ↓ 全部离场
```

| 场景 | 卖点信号 | 卖出时间窗口 |
|------|---------|------------|
| 1.12商业航天 | 批量异动进监管池+涨停183个极致高潮 | 1.12当天或1.13竞价 |
| 1.26贵金属有色 | 45个涨停高潮+金银期货冲高回落 | 高潮次日高开 |
| 3.25能源线华电辽能 | 8板后爆量断板，板块跟风减弱 | 断板当日 |

### 7.2 框架验证结论

详见 `references/framework-validation-report.md`（基于80+份复盘数据逐条检验）。

**核心结论：33项规则测试，30项成功，1项失败，2项模糊。总胜率91%。**

主要修正建议：

1. **区分"连板先锋确认法"和"趋势龙头确认法"**——连板先锋用3天确认法，趋势总龙（如航发展、寒武纪）需另用"贯穿周期创新高"来确认
2. **主线四特征中特征①（带动大盘共振）是硬门槛**——不满足的直接排除，无需继续验证
3. **特征④（抗倒春寒）是充分条件**——前3条符合但扛不住分歧的，大概率是伪主线
4. **秋收预警→确认的时间窗口约1-2天**——这是减仓的最后安全窗口
5. **冲击型冰点完全隔离出四季框架**——规则已验证，框架不适用于外部冲击

### 7.4 风格四季维度初探（2026-05-12新增，待验证）

#### 7.4.1 问题背景

现有框架具备"大盘四季"和"板块四季"两个维度，但2026年5月实战发现，这两层不足以描述市场结构的全部面貌。用户提炼出"大为美、硬为美、趋势为美、次新为美、庄为美"——这是对趋势风格☀️夏长高潮的特征刻画，但框架没有独立的"风格"维度来承载这种认知。

#### 7.4.2 事实依据

从2026年1~5月的复盘数据分析，存在两种风格独立的生命周期：

| 时间 | 连板风格 | 趋势风格 |
|------|---------|---------|
| 1月商业航天 | ☀️夏长（雷科12板、神剑接力） | 跟随，非主导 |
| 1月政策降温退潮 | 🍂秋收（高度从12板压到5-6） | 开始萌芽 |
| 1-2月混沌轮动期 | 混沌，小周期3-5天 | 混沌，跟随轮动 |
| 3月电力周期 | ☀️回升（华电辽能8板） | ☀️混合走强（电力+趋势并存） |
| 3月地缘冲击 | 被冲击打乱 | 被冲击打乱 |
| 4月科技切换 | 🌱低位酝酿，未突破 | 🌱春播（出口链光模块先启动） |
| **5月科技高潮** | **🌱仍在低位未突破** | **☀️夏长高潮（"五美"极致）** |

用户5.10复盘原文："连板风格仍在低位酝酿突破的阶段"——这本身就是对风格的四季定位判断。

#### 7.4.3 两种风格定义

| 风格类型 | 典型特征 | 常见市值 | 主导资金 | 涨幅方式 | 代表周期 |
|---------|---------|---------|---------|---------|---------|
| 🔗 **连板风格** | 连板爆发、情绪驱动、辨识度优先 | <100亿 | 游资+量化 | 连板急拉（10cm/20cm） | 1月商业航天（雷科→神剑→银河） |

#### 7.4.4 与大盘/板块四季的关系

三种四季独立存在，互不同步：

2026年5月12日示例：
- 🏛️ **大盘四季**：☀️夏长末段，🍂秋收预警
- 📦 **光通信板块**：☀️夏长中段
- 📦 **半导体板块**：☀️夏长末段（5.11高潮后回调）
- 🎨 **连板风格**：🌱低位酝酿未突破
- 🎨 **趋势风格**：☀️夏长高潮

#### 7.4.5 策略含义

| 风格组合 | 最优策略 |
|---------|---------|
| 连板风格☀️ + 趋势风格☀️ | 重仓，两种手法并行 |
| 仅连板风格☀️ | 做接力、打板、龙头连板持股 |
| 仅趋势风格☀️ | 做低吸、趋势持有、以中军为核心 |
| 两种风格切换中 | 轻仓，等风格确认后再加重仓位 |
| 两种风格❄️ | 空仓，风格全灭=无赚钱效应 |

1月偏连板风格，做雷科连板接力是对的。5月趋势风格☀️但连板风格🌱——做连板接力的胜率天然低于做趋势低吸。这不是"市场赚不赚钱"，而是**风格错配导致手法胜率下降**。
