# 野村证券全球存储研报精读

> 来源：野村证券 2026-05-15 发布 | 老涂2026-05-18提供

## 核心主张

存储行业正在从"周期性行业"变成"结构性增长行业"，市场还在用旧框架定价，三星和海力士被严重低估。

## 需求端：指数级增长

乘法效应框架：内存需求 = 用户数 × 参与时长 × 任务复杂度 × Token消耗 × Agentic AI加速系数

**Token消耗量化：**
- 简单翻译：40 Token
- RAG问答：6,040 Token
- 图像生成：30,500 Token
- 生成1小时视频：1亿 Token
- 从翻译到视频，差了250万倍

核心结论：未来五年存储需求可能增长数千倍，供给增速CAGR仅约30%（五年约5-6倍）

## 自我强化的投资循环

AI服务商未来五年收入可从当前700亿美元扩张超过100倍。Anthropic预计2027年盈亏平衡，OpenAI目标2029年盈利。AI需求已过"奇点"，主要驱动力已从消费级迁移到企业AI和主权AI。

## 供需结构

**DRAM晶圆产能扩张（千片/月）：**
三星：2024末704→2028F 910（+7% CAGR）
SK海力士：474→803（+14%）
美光：345→560（+13%）
长鑫（CXMT）：200→500（+26%）
合计：1,723→2,981（+15%）

**HBM产能（千片/月）：** 2024:181→2025:380→2026F:490→2027F:700→2028F:900
HBM扩容占用Commodity DRAM产能，Commodity供给更加紧张。

## LTA框架（最重要的新变量）

与过去周期最大区别：合同期从1年以内→3-5年，预付款从无→有，CSP承担部分存储厂扩产Capex，取消代价从低→高。
本质：从"价格锁定合同"变成"战略合作协议+产能捆绑"。

## 市场规模

全球存储收入：2024年1,810亿→2025年2,640亿→2026F 8,520亿→2028F 17,340亿
存储在DC Capex占比从9%跳到20%（2026年）→结构性转变

## 估值重估

当前三星6x P/E（隐含风险溢价19%），海力士6x P/E（隐含24%），TSMC 20x（约1%）
目标价：三星590,000韩元(+118%)，海力士4,000,000韩元(+120%)

## 三大风险
1. CSP Capex可持续性/AI变现 → 野村认为担忧已过时
2. **美国数据中心电力短缺** → 实质性风险，需卫星图像跟踪
3. 长端利率上升/项目融资成本上升

## 小禾学习收获

1. **框架性重估思维**：不仅调价，而是改变行业性质定义
2. **乘数效应模型**：多个变量乘数放大会改变结论
3. **LTA改变行业属性**：从"卖货"到"卖产能"，估值体系应不同
4. **风险溢价视角**：6x PE隐含19%风险溢价→关键在于判断溢价合理性
