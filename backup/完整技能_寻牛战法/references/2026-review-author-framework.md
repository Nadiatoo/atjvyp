# 2026复盘作者思维框架演进实录

> 2026-05-15 发现：复盘文件（80+份）、盘前热点（3月）、单篇逻辑文章（抱团瓦解、美债风暴等）**均为同一位作者**。
> 此前把复盘当"市场数据"，把单篇当"分析观点"，是割裂的。打通后发现它们是一个人在用同一套框架每日检验市场。
> 学习目标：不是学他对市场的具体判断（时效性太强），而是学他的**思维框架和工具进化路径**。

---

## 作者身份推断

- 职业：职业交易员/投研人士
- 风格：每日撰写完整复盘（四层框架：大盘→情绪→题材→北证），周末深度复盘，偶尔写单篇逻辑文章
- 能力范围：宏观地缘 + 产业链分析 + 情绪周期 + 北交所
- 输出纪律：全年每天写复盘，已持续至少5年

## 全年框架演进五阶段

### 阶段一：框架创建期（1月）

**市场背景**：商业航天主升浪，17连阳逼空，政策降温退潮

**框架建立过程**：
- 起点是"数据驱动"——每天用涨跌比、涨停数、成交额做判断
- 1月8日发现连板体系的局限性，升级出"风格分析"（连板vs趋势两套系统）
- 1月13日高潮退潮，框架快速加入"政策因子"（降温手段序列）
- 1月18日深度反思，确认**趋势风格取代连板风格成为主流**

**关键认知**：风格分析比周期分析更重要。市场不是"冰点-修复-高潮-退潮"机械循环，而是不同风格资金在不同环境下交替主导。

### 阶段二：框架检验与降级（2月）

**市场背景**：春节前极致冰点（770红盘），混沌轮动，趋势风格确认

**框架升级**：
- 元框架诞生：主框架失效时**自动降级**到次框架
  - 正常市场：板块主线分析（三层推演）
  - 极致冰点：个股抱团模式 + 试错法
  - 承认"框架失效" → 主动降级 → 不硬拗

**关键认知**：2月12日确认"趋势风格才是贯穿全年的最强风格与主线"——基于90%数据回测支撑。

### 阶段三：黑天鹅考验（3月）

**市场背景**：中东地缘冲击，大盘4190→3813，跌幅9%

**框架进化最大的一月**：
- 地缘政治正式从"背景板"升级为独立分析维度
- 发明"双锚定体系"（指数锚+情绪锚）在极限市况中找底
- "三线博弈"框架（科技线/能源线/冲突线）
- 终局思维：给出两种情景及应对，不赌方向
- 策略重心从"赚多少钱"降为"活下去"

**关键认知**：正常分析框架在黑天鹅面前必然失效。框架的韧性不在于它能预测黑天鹅，而在于它**知道自己失效时该做什么**。

### 阶段四：复位与主线切换（4月）

**市场背景**：地缘缓和，底部修复，新主线（科技/国产替代）确立

**框架复位**：
- 4月8日地缘缓和信号出现后，框架迅速从"生存模式"切换回正常分析
- 准确识别国产替代为下一阶段主线（4月26日周末复盘提出）
- "三重风格"体系完整定型（机构大票/趋势小票/连板一波流）

### 阶段五：趋势主升与风格定论（5月）

**市场背景**：科技结构牛，大盘突破4200，趋势风格高潮

- "五句话"风格定论（5月11日）：大为美、硬为美、趋势为美、次新为美、庄为美
- 量能分层精确：1.6万亿以下=地量，2万亿=存量，2.5万亿=活跃，3万亿以上=牛
- 预判牛市急跌（5月10日→5月14日验证）

## 贯穿全年的底层能力

### 1. 框架的"元能力"

不是一套框架打全场，而是在不同市况下自动切换层级的元框架：

| 市场状态 | 适用层级 | 分析工具 | 策略 |
|---------|---------|---------|------|
| 正常主升 | 宏观+产业+情绪 | 三层推演 | 进攻 |
| 分歧/混沌 | 情绪+风格+题材 | 风格识别+轮动判断 | 控仓 |
| 极致冰点 | 情绪数据+个股 | 抱团模式+试错法 | 生存 |
| 黑天鹅 | 地缘+双锚定 | 终局推演+生存三线 | 活下去 |

### 2. 诚实面对不确定性

全年的复盘中，**"无法预判""真看不懂""等市场选择"频繁出现**。不是能力不足，是对框架边界的清醒认知。

### 3. 信号分层

- 竞价数据（5分钟级）— 盘感确认
- 情绪数据（日级）— 涨跌比/涨停/连板高度
- 机构行为（周级）— 大票态度决定主线
- 宏观框架（季度级）— 年度目标/主线方向

### 4. 应对优于预测

每篇都有具体策略，不只是一句"谨慎看多"。策略分三档：什么情况做什么事、什么情况不做什么事、什么情况等。

## 可以学什么

### 可直接用的工具
1. **三线博弈框架**：市场不完全是一个主线，而是多线并存博弈，分析时先识别它们在跷跷板上的位置
2. **双锚定法**：指数锚+情绪锚同时失效才是极端底部，单一锚失守不是
3. **风格先于方向**：先确定当前风格（机构/趋势/连板），再选匹配手法
4. **降级能力**：主框架用不了就别硬用，换个层级继续

### 可以内化的思维习惯
1. **日更纪律**：不是写给别人看，是形成自己的市场感应
2. **自我验证闭环**：每天复盘前一天的判断是否正确，不对立刻改
3. **工具进化**：每次市场换环境，强迫框架升级（不是放弃旧框架，是加新层）

### 这个发现对处理复盘文件的含义

以后读复盘文件时：
- 不是在读独立的每日记录，是在读一个人的思维框架在每天市场中的检验
- 连续读比单篇读更有价值——看他的框架在什么节点变了、为什么变
- 如果某天的判断错了，看他是怎么修正的——这比他对的哪天更有学习价值
