## 核心结构

```
外部变量（十大类）
    ├── A类冲击 → 大盘四季突变 → 修正总仓位
    └── 特定板块影响 → 板块四季突变 → 修正板块方向
              │
              ↓
          板块内核心股 ─┬── 龙头（连板高度）
                        │
                        └── 中军（大资金容量）
              │
              ↓
          老涂做个股买卖决策
```

## 外部变量（十大类）

宏观基本面 / 货币政策与流动性 / 外围市场映射 / 大宗商品 / 政策法规 / 地缘政治 / 资金面 / 市场情绪 / 产业行业 / 经济数据日历

## 事件冲击四级

- 🔴 全局跳变级（跳变>40%）：重新评估四季，调整仓位
- 🟠 结构性冲击级（20-40%）：大盘方向不变，换受影响板块
- 🟡 节奏影响级（8-20%）：不改变四季，仅调仓位权重
- 🟢 局部干扰级（<8%）：不动作，保持观察

基准日期规则：事件前5交易日 + 事件后15交易日

核心逻辑：位置 + 量能 + 内部结构 三维交叉验证
