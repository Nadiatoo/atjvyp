# 收盘复盘（15:30后cron）标准输出格式

2026-05-21 首次验证，用于收盘后15:30-16:00的cron任务。

## 输出结构（按顺序）

```
📊 收盘复盘（MM/DD HH:MM）— {一句话核心判断}

【指数收盘】
上证 XXXX(-X.XX%) | 深证 XXXXX(-X.XX%) | 创业板 XXXX(-X.XX%) | 科创50 XXXX(-X.XX%) | 上证50 XXXX(-X.XX%)
{午后变化描述：如"科创50从+0.33%暴跌至-3.70%，80分钟跌超4%"}

【四层定位】
🌍 宏观底色：{有无单一利空/催化事件，是否内生性}
↓
🏛️ 大盘四季：{季节判断 + 跳季说明}
↓
📦 板块四季：{最强板块+涨停数（变化趋势），重点板块退潮/增量}
↓
🎨 风格四季：{连板❄️/☀️ + 趋势❄️/☀️}
↓
📈 策略：{仓位建议 + 手法匹配说明}

【连板结构】
{连板高度}板 {最高标名称}({概念}·{状态：独立/跟风/炸板回封等})
{次高}板 {名称}
{2板数}板 {各名}

【冬藏信号全检】（今天是否冬藏初段）
① 总涨停{数字}（{判定}） ✅/❌
② 增量板块证伪 — {板块名}{变化描述} ✅/❌
③ 尾盘恐慌炸板 — {描述} ✅/❌
④ 利好无法兑现 — {描述} ✅/❌
⑤ 双风格同时冬藏 ✅/❌
⑥ 跌停{数字}只（其中连续跌停≥2的{数字}只）

① {竞价信号}
② {核心指标}
③ {风格信号}
④ {催化变量}
⑤ {特殊关注}

【总结】
{一段话定调}
```

## 数据采集顺序（已验证cron环境）

```
Sina API (指数) → AkShare stock_zt_pool_em (涨停今日) 
→ stock_zt_pool_dtgc_em (跌停今日) 
→ stock_zt_pool_em (涨停昨日，对比)
→ stock_info_global_em (新闻)
→ 六信号核查
→ 输出
```

## 关键注意事项

1. **对比昨日是必须的** — 单日绝对值无意义，34涨停本身是低还是极低？必须有昨日对比（61→34腰斩才有说服力）
2. **跌停分析不可跳过** — 即使跌停数少也要提一句"跌停X只，无集中"；跌停>15时必须详细分析
3. **冬藏六信号是每天必查** — 不是只在疑似冬藏时才查，每天都过一遍清单，防止漏判
4. **delivery方式** — `mcp_openclaw_message_bus_send(from="小禾", to="all")`
5. **与盘前简报格式协调** — 盘前用 `references/cron-morning-briefing-format.md`，收盘用本文件

### 冬藏+正向催化的收盘后处理（2026-05-22补充）

收盘后出现重大正向催化（如隔夜SMIC获批/美股大涨）时，**不要因此修改冬藏定位**。正确顺序：

1. 先完成收盘复盘 → 确认当日冬藏状态，如实记录
2. 再评估催化级别，写入盘前简报
3. 两者分开：收盘复盘回答"今天发生了什么"，盘前简报回答"明天可能怎么走"
4. 不在收盘复盘中预判明日催化影响——会混淆分析，导致收盘复盘失去当日准确性

**akshare新闻列名备忘：** `ak.stock_info_global_em()` 返回中文列名：`['标题', '摘要', '发布时间', '链接']`，遍历时按列名访问。
