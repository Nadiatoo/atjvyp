# 个股查询/研报工作流程

## 适用场景
当用户询问某只个股的基本面信息、解禁、股东、财务数据时。

## 工作流程

### 第一步：确认股票代码
```python
import tushare as ts
pro = ts.pro_api()
df = pro.query('stock_basic')
# 按名称搜代码
```

### 第二步：多源数据采集

| 信息类型 | 数据源 | 获取方式 |
|---------|--------|---------|
| 行情数据 | Tushare Pro | `pro.daily(ts_code=...)` 日线 |
| 股东/解禁 | 东方财富 Chrome | 导航到 emweb F10 股东研究页提取 |
| 新闻/公告 | 东方财富/Chrome | 搜索关键词 |
| 题材关联 | knowledge_base.db | `query_kb.py --company 名称` |
| 概念/行业 | 东方财富行情页 | Chrome提取 |

### 第三步：交叉验证
- 知识库数据 + 网络最新数据 + Tushare财务数据 三者对比
- 不一致时以公告/官方数据为准

### 第四步：输出结构

```
股票基本信息（代码/行业/市值）
↓
关键事件（解禁/减持/公告等）
↓
题材覆盖（知识库中有哪些相关题材）
↓
判断与风险提示
```

## 注意事项
- ❌ 客户持仓个股分析禁止套寻牛四季框架
- ✅ 用专业投顾视角：行业地位、产业链位置、催化剂、研报观点
- ✅ 知识库里没有就上网查、拉Tushare、开Chrome翻东方财富
- ✅ 直接给结论，不要问用户"怎么办"
