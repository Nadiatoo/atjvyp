# 寻牛战法 · 五层逻辑框架

> 提取时间：2026-05-16，来自老涂要求"把逻辑想通想透"后的深度解读
> 背景：小C做了5年指数级回测（恐慌买入→高潮卖出），发现统计有效但实战无法执行
> 原因：回测跳过了中间层，直接在大盘情绪信号上做买卖决策

---

## 一、完整逻辑链

这套体系的根基是一条因果链，每层依赖上一层：

```
层1【哲学根基】→ 市场由人组成 → 人有情绪贪嗔痴 → 情绪有周期
     ↓
层2【四季框架】 → 周期可分春夏秋冬 → 每个季节有独特特征和应对
     ↓
层3【三要素】   → 选板块 = 天时(情绪位置) + 地利(板块位置) + 人和(产业逻辑×预期差)
     ↓
层4【四层执行】 → 大盘定仓位 + 板块定方向 + 风格定手法 + 个股定买卖
     ↓
层5【节奏控制】 → 因敌变化而作战（市场矛盾变了，应对就变）
```

**关键认知：这套框架天然就是多层次的。你不能跳过中间层。**

---

## 二、为什么指数级回测没有实战意义

小C的回测逻辑：上证跌7%→买入，涨8%→卖出。

这个逻辑对应到五层框架里，相当于：

**用层1（情绪周期）直接推导买卖决策，跳过了层2（四季辨识）、层3（板块筛选）、层4（个股执行）整个中间结构。**

就好比一个农民只看天气预报说"明天降温"，就决定种什么菜、种多少、什么时候收——他跳过了看墒情、看地力、看种子质量这些关键环节。

**所以：**
- 统计上能做出超额（恐慌后60日胜率91%确实有效）✅
- 但实战中无法执行（因为"大盘跌7%"只是一个仓位信号，不是买卖点）❌

---

## 三、真正的买卖决策路径

寻牛战法的实战决策不是"指数跌X%→买"，而是：

```
看大盘在冬藏尾声 → 判断情绪位置对（天时✓）
    → 找到位置低的潜力板块（地利✓）
    → 确认板块有产业逻辑支撑（人和✓）
    → 等板块与大盘共振 → 出手板块内的龙头/中军
```

**大盘只做一件事：定总仓位基调。它不是买卖标的。**

## 四、正确的量化方向

如果要量化验证寻牛战法，应该做的是：

| 方向 | 优先级 | 核心问题 | 前置依赖 |
|------|--------|---------|---------|
| A. 板块四季判定 | 🔴最高 | 能否用量化信号识别板块处于哪个季节？ | 板块级数据管线 |
| B. 主线生命周期 | 🟡中 | 主线板块从启动到退潮的量价结构？ | 方向A完成 |
| C. 龙头/中军超额 | 🟡中 | 选中主线后龙头/中军的相对超额？ | 方向A+B完成 |

**方向A的核心问法不是"涨多少买、跌多少卖"，而是"这个板块现在什么季节？"**
