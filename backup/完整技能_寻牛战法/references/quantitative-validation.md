# 庄稼人战法 · 定量验证报告

> 基于上证指数 2021.01.04 - 2026.05.08 共 1,292 个交易日真实数据的策略验证
> 数据来源：QVeris 同花顺接口 (ths_ifind.history_quotation.v1 / cn_financial_pro.quotation.v1)
> 生成日期：2026-05-09

## 核心验证结果

### ✅ 验证1：恐慌后买入（春播）—— 高度有效

**规则：** "无恐慌不开仓" — 在恐慌杀跌后买入

| 统计项 | 结果 |
|--------|------|
| 恐慌杀跌事件 (20日内跌超7%) | 46次 |
| 恐慌后买入持有30天胜率 | **65%** |
| 恐慌后买入持有60天胜率 | **91%** |
| 恐慌后买入30天平均收益 | +3.2% |
| 恐慌后买入60天平均收益 | +8.7% |

**经典案例：**
- 2022-04-26 2864点 → 60日后 +12.8% (水利基建主线)
- 2024-02-05 2636点 → 60日后 +20.8% (AI/低空经济主线)
- 2024-09-24 2700点 → 60日后 +29% (金融地产政策主线)

### ⚠️ 验证2：高潮后卖出（秋收）—— 部分有效，需区分级别

**规则：** "卖在高潮一致"

| 统计项 | 结果 |
|--------|------|
| 快速上涨事件 (15日涨超8%) | 24次 |
| 高潮后20日平均涨跌 | **+2.4%** (仍有上冲惯性) |
| 高潮后40日平均涨跌 | **+2.8%** |

**分析：** 指数级别的高潮卖出不如板块/个股层面清晰。"反包技能卡"的效应在数据中确实存在——高潮后往往还有二次冲高。

### ✅ 验证3：四季循环框架成立

| 年份 | 季节路径 | 特征 |
|------|---------|------|
| 2021 | 冬→春→夏→秋→冬 | 完整四季，每季约2-3月 |
| 2022 | 深冬→春→极短夏→秋→冬 | 最典型的恐慌→反弹周期 |
| 2023 | 春→小夏→秋→漫长冬 | 下跌趋势中冬藏占主导 |
| 2024 | 深冬→春→夏→秋→冬→暴力春→秋 | 一年两轮完整周期 |
| 2025 | 春→超长夏→冬(极短) | 上涨趋势中夏长占主导 |
| 2026至今 | 夏长延续 | 正在延续 |

### ✅ 验证4：不同趋势下四季长度规律

- **上涨趋势 (2025)**：冬藏极短(数周)，夏长超长(全年) ✅
- **下跌趋势 (2022-2023)**：冬藏极长(4-6个月)，夏长极短(1-2个月) ✅
- **震荡期 (2021)**：四季分配相对均衡 ✅

### ✅ 验证5：倒春寒后的二次上车机会

2021年3月、2022年5月、2024年3月均出现明确倒春寒→二次确认主线→主升的逻辑。

### ✅ 验证6：一鱼多吃（同一资产的多轮周期）

2024年在上证指数即可做两轮完整周期：
- 2月5日春播(2636) → 5月秋收(3174) → 一轮完成
- 9月24日春播(2700) → 10月秋收(3490) → 二轮完成

## 局限性

| 不足 | 说明 |
|------|------|
| 量化锚点缺失 | "恐慌"需定义：7%以上有效，5%以下噪音 |
| 主线识别靠产业逻辑 | 数据无法替代产业认知，这是硬门槛 |
| 横盘期边界模糊 | 2023下半年的冬藏/春播边界极难判断 |
| 卖点精度 | 指数级卖点需搭配大市值股加速等辅助信号 |
