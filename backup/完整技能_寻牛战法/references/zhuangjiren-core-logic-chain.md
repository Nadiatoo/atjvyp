# 庄稼人战法·核心逻辑链

> 基于原典（11,846字原文）的系统性提炼。
> 生成时间：2026-05-16，经老涂确认逻辑无误。

---

## 一、体系沿革

```
庄稼人战法（底层哲学）
    ↓ 2022年股帮专栏"短线解盘"
彪哥战法（vintage应用版本，含具体买卖规则+案例）
    ↓ 2026年1-5月80+份复盘实战验证 + 量化时代适配升级
寻牛战法（当前迭代，继承"道"、重写"术"）
```

**庄稼人战法** = 底层哲学，不可变。核心命题："市场由人组成→人有情绪→情绪有周期→周期分四季→四季不同做不同事"。

**彪哥战法** = 2022年的应用版本。案例（2020券商、2021鸿蒙、2022水利等）和具体买卖规则是对当时市场环境的应对，不可直接套用于量化时代的市场。

**寻牛战法** = 基于底层原理、针对2025-2026年量化生态重新提炼的当前版本。继承了情绪周期和四季框架的底层逻辑，但应用规则（大盘/板块/风格三层独立判定、龙头7维验证、概念主场客场归属等）已独立迭代。

## 二、五层逻辑链

寻牛战法的完整逻辑从底层到执行分五层，每层依赖上一层，不可跳越：

### 层1：哲学根基
- 市场由人组成 → 人有贪嗔痴 → 情绪有周期
- 只要交易主体是人，这套框架就永远有效
- 量化只是放大了情绪波动（加速了周期转换），没有消除情绪

### 层2：四季框架（识别系统）
- 春播：恐慌出清、聪明钱试探、温和放量
- 夏长：共识强化、放量上涨、赚钱效应扩散
- 秋收：高潮一致、去弱留强、分步兑现
- 冬藏：退潮补跌、缩量麻木、等待信号
- 四季是识别工具，不是预测工具

### 层3：三要素（筛选系统）
- 天时：情绪位置对（冬藏尾声的恐慌才是春播点）
- 地利：板块位置低（均线附近、没获利盘）
- 人和：产业逻辑硬（全市场比较找预期差最大的方向）

### 层4：四层执行（决策系统）
- **大盘** → 定总仓位（不是买卖标的）
- **板块** → 定方向（找处于春/夏的板块）
- **风格** → 定手法（连板风格做接力，趋势风格做低吸）
- **个股** → 定买卖（板块内的龙头+中军）

### 层5：节奏控制（自适应系统）
- "因敌变化而作战"——市场核心矛盾变了，应对就变
- 主线分析框架可能在极致冰点时降级为个股抱团模式
- 框架本身有"元能力"：知道什么时候该用哪层框架

## 三、层级铁律

**寻牛战法的买卖决策只发生在层4的"个股"子层。** 其他层的判定都是约束条件，不是买卖信号。

| 层级 | 作用 | 能做的决策 | 不能做的决策 |
|------|------|-----------|------------|
| 大盘/指数 | 定总仓位 | 仓位重/轻/空 | 不能：以此作为买卖单个板块或个股的依据 |
| 板块 | 定方向 | 关注哪些板块、回避哪些板块 | 不能：在板块指数上做买卖决策 |
| 风格 | 定手法 | 用连板还是趋势手法 | 不能：决定具体买卖哪只股票 |
| 个股 | 定买卖 | 出手/持有/兑现具体的股票 | — |

**回测/验证必须明确层级**：
- 指数级回测 → 只验证"总仓位方向判断是否正确"
- 板块级回测 → 验证"板块四季切换的可识别性"和"主线识别准确性"
- 个股级回测 → 验证"龙头/中军的相对超额收益"

**跳级验证（如在指数级做买卖决策回测）结果在统计上可能有效，但无法执行到实战中。**

## 四、量化时代的适配要点

原典写于2022年，以下五点是从2026年实战中提炼的修正：

1. **季节转换速度加快2-3倍**：量化放大了情绪波动，以前的"天"变"小时"
2. **反包技能卡效力递减**：第一次仍有效，第二次后胜率骤降（被量化反收割）
3. **多季节并存成为常态**：不同板块/风格可能同时处于完全不同的季节
4. **秋收节奏前置**：高潮当天就要考虑出货，不等"看到分歧再卖"
5. **冰点波动率放大**：冲击型跌得快反弹也快，内生型跌得慢磨底长

## 五、常见误区

| 误区 | 正确理解 |
|------|---------|
| 寻牛战法是技术指标系统 | 底层是情绪周期哲学，不是技术指标。MACD/KDJ等指标仅为辅助验证 |
| 四季框架用来预测 | 四季是识别工具，不是预测工具。核心是"现在什么季节"，不是"下个季节什么时候来" |
| 分仓=分散到不同股票 | 分仓=分散到不同板块的龙头/中军。单一板块内的多只股票不叫分仓 |
| 秋收=清仓 | 秋收=去弱留强逐步兑现，不是一次性清仓。核心公司可以持有到反包技能卡走完 |
| 指数级验证=战法有效 | 战法的买卖决策在个股层面，不在指数层面。指数级验证只能证明"情绪周期确实存在" |
