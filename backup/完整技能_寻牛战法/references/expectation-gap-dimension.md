# 预期差维度 — 寻牛战法第五层分析

## 核心概念

**预期差 = 市场认知 vs 现实变化之间的偏差。**

庄稼人战法判断主线的底层逻辑就是预期差识别。原文《如何尽早判断出新一轮市场主线》的四特征，翻译成预期差语言：

| 原文特征 | 预期差含义 | 判断标准 |
|---------|-----------|---------|
| 📉 位置低（地利） | 市场已充分price in悲观 | 板块距60日线-5%~-15%，无人关注 |
| 🔬 产业逻辑好（人和） | 现实变化正在发生，市场还不知道 | 上游涨价/产业政策/技术突破 |
| 🛡️ 扛分歧/倒春寒 | 聪明钱在逆势买入修复预期差 | 大盘跌它不跌，甚至逆势走强 |
| 🚀 与大盘共振 | 预期差修复被广泛认可 | 板块涨→大盘跟涨，不再是独立行情 |

## 预期差三大来源

| 来源 | 描述 | 寻找方向 | 验证信号 |
|------|------|---------|---------|
| **产业趋势 vs 市场定价** | 产业链上游异动但下游还没反应 | 美股传导（MU→A股存储）、上游涨价（MLCC→元件） | 上游涨了但A股对应板块还没涨停 |
| **财报/数据 vs 一致预期** | 实际发布数据超券商一致预期 | 业绩预告、Tushare forecast数据 | actual > consensus |
| **政策信号 vs 市场反应** | 政策真实落地但被市场无视 | 冬藏/秋收里出的政策 | 政策日大盘不涨甚至跌 |

## 预期差四象限评分

```
              现实变化强        现实变化弱
市场认知悲观    ★★★★☆ (春播)    ★★☆☆☆ (冬藏)
市场认知乐观    ★★☆☆☆ (秋收)    ★☆☆☆☆ (混沌)
```

**最佳春播候选：** 市场认知悲观 + 现实变化强 = 预期差最大。这就是元件/PCB在5/22冬藏中段时的状态。

## 融入四层定位

在原有四层定位后追加预期差评分：

```
大盘四季 → 板块四季 → 风格四季 → 预期差评分 → 策略输出
```

评分标准（单一板块）：

| 分数 | 含义 | 市场认知状态 | 现实变化状态 |
|:----:|------|------------|------------|
| ★★★★☆ | 预期差最大 | 无人关注/极度悲观 | 产业变化真实发生 |
| ★★★☆☆ | 预期差中段 | 开始有人讨论 | 变化在扩散 |
| ★★☆☆☆ | 预期差尾声 | 共识形成 | 变化已充分反映 |
| ★☆☆☆☆ | 负向预期差 | 过度乐观 | 变化开始走弱 |

## 实战应用：冬藏中的预期差

**冬藏中段是预期差最大的窗口。** 此时：

- 市场认知：极度悲观（"完了，又要跌了"）
- 现实变化：可能正在企稳（跌停骤降、板块效应萌芽）
- 预期差：最大

但不是所有冬藏中段出现的板块效应都是真主线。要用原文四条验证：

1. 春播日能带动大盘共振（不只是板块自己涨）
2. 扛倒春寒（大盘分歧时表现有韧劲）
3. 位置低 + 产业逻辑好（地利人和）
4. 板块阵型完整（先锋+中军+后排）

满足这些的板块，预期差修复的确定性最高。
