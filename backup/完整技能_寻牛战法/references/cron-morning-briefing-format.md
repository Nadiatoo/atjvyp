## Cron 盘前简报 · 标准输出格式

由 cron 早盘任务自动生成，数据源全部经 cron 环境验证。
原则：框架分析驱动，不是数据堆砌。

### ⚠️ 启动流程（必须执行在简报之前）

每次cron早盘任务开始时：
1. **检查消息总线** — `mcp_openclaw_message_bus_check(agent="小禾")`，过滤出今天的新消息，忽略前日已处理的旧消息
2. **处理积压文件** — `~/.hermes/pending_messages.txt` 如有内容，先处理
3. **确认当前日期** — 从 conversation start timestamp 确认今天是几月几日周几
4. **加载隔夜外围数据** — 见下节数据采集顺序

### 产出结构（每个区块独立，顺序固定）

```
📊 盘前简报 | YYYY-MM-DD HH:MM

### 🌙 隔夜外围
[美股三大指数表格 + 关键个股涨跌 + 大宗商品]

### 🇨🇳 A股早盘
[主要指数表格 + 一句话定性]

### 🔥 今日最大信号
[最有意义的板块/个股事件，用数据说话]

### 🏛️ 连板结构
[连板分布表 + 高标变化对比前日]

### 🎯 框架分析
**大盘四季：** {判断}
**板块四季：** {最强板块的阵型分析}
**风格四季：** {连板 vs 趋势判断}
**主线清晰度：** {清晰/混沌/可能破局}

### ⚡ 策略含义
[仓位 + 方向 + 手法 + 风控]

**今日关键观察点：**
1. ...
2. ...
3. ...
```

### 输出检查清单

- [ ] 美股数据有表格（指数+核心个股）
- [ ] A股指数有表格（五大指数）
- [ ] 涨停数据含行业分布TOP + 连板分布 + 高标详情
- [ ] 核心信号明确标注（🔥/★ 等标记）
- [ ] 框架分析四层齐全，不跳层
- [ ] 有前日对比（连板变化、高标演进）
- [ ] 策略含义具体（仓位数字、方向板块名、手法名称）
- [ ] 如有隔夜正向催化，需做「冬藏中的催化处理」三步判断（见SKILL.md）
- [ ] **08:30版本（距竞价45分钟）**：追加冬藏催化高开风险量化表（上证高开幅度×概率×含义），见SKILL.md「冬藏中催化高开风险量化表」

### 夜间/凌晨简报（00:00-08:00 cron 专用）

凌晨时段市场未开盘，生成格式侧重「隔夜外围定调 + 催化初筛」：

**区块一：外围收盘** — US三大指数 + 核心科技股 + 中概 + 商品期货
**区块二：隔夜催化** — 按优先级列出所有重要新闻，标注对A股影响方向（✅/⚠️/🔴）
**区块三：A股回顾** — 前日收盘数据速览（指数+涨停+跌停）
**区块四：四层定位** — 大盘冬藏确认、风格定位、板块分析
**区块五：策略与今日三看** — 仓位建议 + 开仓条件（竞价涨停/跌停/板块效应三项门槛）
**区块六：下次更新预告** — 如"08:45盘前简报"

数据源流动：Sina API（指数）→ akshare stock_info_global_em（新闻）→ 框架分析

### 常见陷阱

- ❌ 指数只列数值不列涨幅 → 必须同时有涨幅%
- ❌ 只说板块很强不说多强 → 用数据（8只/36%/89亿封单）
- ❌ 不断句的大段文字 → 用表格/列表结构化
- ❌ 把数据和分析混在一起 → 先数据后分析，泾渭分明
- ❌ 依赖Sina新闻Feed找催化剂 → 已验证返回2024年旧数据，改用Baidu浏览器搜索
- [ ] 板块判断缺少阵型分析 → 必须明确先锋/中军/后排
- [ ] Day 0爆发未做持续性评估 → 参见 `references/day0-eruption-evaluation.md` 五维框架
- [ ] 今天的数据不对比昨天
