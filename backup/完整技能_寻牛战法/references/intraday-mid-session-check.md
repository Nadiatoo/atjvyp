# 盘中30分钟确认流程（10:00/10:15/14:00检查）

## 用途

开盘后30分钟（10:00）或下午开盘后30分钟（14:00），对盘前分析的推论做首次校验。

**核心原则：** 盘中检查不是重新做完整分析，而是「验证/修正盘前推论」——增量即价值。

---

## 检查清单

### 1️⃣ 指数验证：高开低走还是加速上行？

| 检查项 | 判断标准 | 信号含义 |
|--------|---------|---------|
| 全部指数涨跌幅 > 开盘涨幅 | ✅ 加速上行 | 最强势信号，主仓可维持 |
| 部分指数涨跌幅 < 开盘涨幅 | ⚠️ 分化 | 结构性问题，需关注结构方向 |
| 全部指数涨跌幅 < 开盘涨幅 | ❌ 高开低走 | 盘前催化被获利盘消化，减仓应对 |

**数据源（cron环境）：** 东方财富 Push API `ulist.np/get`

### 2️⃣ 板块验证：盘前预期的方向对吗？

**30分钟足够验证「盘前判断的板块方向」是否准确。**

| 场景 | 含义 | 动作 |
|------|------|------|
| 预期板块领涨且持续 | ✅ 方向正确 | 维持方向 |
| 预期板块领涨但被其他板块超越 | ⚠️ 方向偏差 | 修正方向到新领涨板块 |
| 预期板块跌幅前列 | ❌ 方向完全错误 | 放弃盘前判断，跟随实际主力 |

**数据源：** 东方财富 Push API `clist/get` (t:2=行业板块, t:3=概念板块)

### 3️⃣ 涨停验证：板块效应存在吗？

| 涨停变化 | 含义 |
|---------|------|
| 09:30的~12只 → 10:00的22+只 | ✅ 增量入场，强势 |
| 09:30的~12只 → 10:00的10-15只 | ⚠️ 开板多，强度一般 |
| 09:30的~12只 → 10:00的5-8只 | ❌ 开板潮，催化兑现完毕 |

**数据源：** `clist/get` (fs=m:0+t:6+f:!50, 统计 f3>=9.9 的个数)

### 4️⃣ 资金流向验证：真钱还是情绪？

领涨板块的 `f62`（净流入金额）比涨幅更能区分真主线和情绪跟风。

| 情景 | 判断 |
|------|------|
| 领涨板块 + 高净流入(10亿+) | ✅ 真主线，大资金入场 |
| 领涨板块 + 净流出 | ⚠️ 情绪跟风概率大 |
| 涨幅中等 + 超高净流入(30亿+) | ✅ 隐藏主线，资金在悄悄布局 |

### 5️⃣ 超预期发现：盘前遗漏了什么？

30分钟内常出现盘前未预料到的板块异动：
- 证券异动(+3%+放量) → 全面行情信号
- 全新概念爆发 → 凌晨催化被遗漏
- 前日强势板块全面退潮 → 板块切换确认

## ⚠️ 关键补充：10:10-10:20 第二波现实校验

### 为什么需要第二波校验？

10:00检查可能给出**虚假正面信号**。因为开盘前30分钟的买入资金来自隔夜积累的竞价挂单+早盘情绪单，这些资金在10:00前后几分钟才基本耗尽。10:00看到的强势可能是"最后的买盘余温"，不是市场真正的承接力。

**10:05看着很美 → 10:15原形毕露的经典路径：**
```
09:30      满屏涨停 → 10:00 数据强势 → 10:15 高标炸板/中军回吐 → 10:30 确认退潮
  ↑               ↑                    ↑                      ↑
  竞价+首波买盘   情绪仍在惯性中        买盘耗尽，真承接曝光    趋势确认
```

### 核心检测：三个"裸泳检查点"

按顺序检查——**前面的炸了后面的更不可能守住。**

#### 🔴 检查1：最高连板标的是否炸板

**这是第一道警报。** 高标（6板以上）在10:10前后炸板=连板情绪从早盘狂热中清醒。

| 现象 | 判断 |
|------|------|
| ✅ 高标仍封死涨停 | 连板情绪坚实 |
| ⚠️ 高标炸板后在中途（+6%~+9%） | 连板情绪松动，观察能否回封 |
| ❌ 高标炸到平盘（<+3%或转绿） | **连板情绪崩溃信号** |

**检测：** 前日Top3高标 + 近期辨识度标的实时检查。

#### 🟠 检查2：板块前排涨停股是否开板

高标炸板的恐慌向板块前排传导。检查主线板块内**第2-3只涨停股**状态：

| 现象 | 判断 |
|------|------|
| ✅ 前排全部封死 | 主线坚实 |
| ⚠️ 龙头封死但#2涨停股开板 | 后排分歧，但龙头扛住了 |
| ❌ #2涨停股大幅开板、龙头也松动 | **主线出现分歧** |
| ❌ 龙头从未封死 | **资金开盘就没完全认可** |

**检测：** 不只查龙头（京东方A封死≠板块安全），查#2、#3的位置。

#### 🟡 检查3：日内中军（10:00时大涨的大市值股）是否回吐

高标炸板→板块分歧后，资金离场潮从高位大市值股抽血。

| 现象 | 判断 |
|------|------|
| ✅ 中军稳定（距10:00价格±1%内） | 大资金没走 |
| ⚠️ 中军回吐3-5% | 大资金在减仓 |
| ❌ 中军从+8%以上回落到<+1% | **大资金清仓信号** |

**检测：** 查10:00时涨幅>5%的大市值股（成交额>10亿），对比10:10-10:20的价格。**中军回吐幅度比指数回撤更敏感。** 2026-05-21北方华创回吐8.43%时上证才回撤0.54%。

### 综合判断规则

| 三检查结果 | 结论 | 动作 |
|:---------:|:----:|:----:|
| ✅✅✅ 全部正常 | 早盘强力确认 | 维持仓位 |
| 仅🟡中军回吐 | 结构分化但主线仍在 | 减仓跟风股，保留核心 |
| 🟠板块分歧+🟡中军回吐 | 冲高回落确认 | 减仓至5-6成 |
| 🔴高标炸板+🟠板块分歧+🟡中军回吐 | **三重确认退潮** | 大幅减仓至4成以下 |

### ⚠️ 模拟实战案例（非真实历史数据）

下方案例为**假设场景**，用于演示三重检查如何工作。所有数据为教学目的，非任何具体交易日的历史记录。

**假设场景：** 盘前看好面板和半导体，开盘竞价强势
- 10:05数据看似一切正常（上证+0.83%，面板+5.21%，京东方A涨停封死95亿）
- 但10:10-10:15三重检查全部亮红灯：
  1. 🔴 利仁科技(9板高标) 涨停→+0.58%
  2. 🟠 深天马A(面板#2) 涨停→+6.26%，TCL科技(面板#3) 涨停价触及即回
  3. 🟡 北方华创(半导体中军)+8.55%→+0.12%，国元证券+8.83%→+3.13%
- **判断：** 早盘冲高=情绪高潮退潮，三重确认触发减仓

### 2026-05-21 盘中校验实录

当日实际走势与上述模拟案例不同——面板中军扛住了10:15压力窗口。

**11:05数据快照：**
| 指数 | 涨跌幅 | 信号 |
|:----|:------:|:----:|
| 上证 | +0.34% | 低开高走修复 |
| 深证 | +1.10% | 加速，深市领涨 |
| 科创50 | +1.04% | 连续3天阳线 |
| 成交额 | ~1.91万亿(半日) | 高水位 |

**板块结构：**
| 板块 | 涨停数 | 核心发现 |
|:----|:-----:|:--------|
| **光学光电(面板)** 🚀 | **9只** | 京东方A封板65亿，无炸板 |
| 汽车零部件 | 6只 | 德赛西威封板 |
| 元件(PCB) | 3只 | 鹏鼎控股2300亿封板 |
| 半导体 | ❌ **1只** | 从昨日6只退潮 |

**三重检查结果（10:10-10:20推断）：**
1. 🔴 检查1（高标）→ ⚠️ 利仁科技(9板)炸板1次回封，封单仅0.42亿极弱；威龙(7板)换手20%正常
2. 🟠 检查2（板块前排）→ ✅ 京东方A全天封死无炸板；深天马A无炸板；亚世光电炸3次回封（后排分歧）
3. 🟡 检查3（中军回吐）→ ✅ 京东方A(65亿封单)未回吐；鹏鼎控股(封3板→剩0.8亿)封单减弱但仍封

**判断：** 中军扛住了，板块效应确认存在。不同于模拟案例中的三重退潮信号，面板当天是「中军坚挺、后排分歧」的结构分化，未触发减仓。

### 结论

**10:00的数据是"想买的人"给的——10:15的数据是"想卖的人"给的。** 真正能说明承接力的是10:10-10:20的数据。两个时间点结合看，构成完整校验链。

## ⏰ 窗口错过处理：10:30之后的盘中检查

当cron在标准检查窗口（10:00/10:15、14:00）之后触发时（如11:00），核心问题从「情绪验证」切换到「结构对比」——不做开盘用的三重裸泳检查，做存量数据快照。

### 10:30后检查要点

1. **跳过三重裸泳检查** — 那是开盘专用。10:30后炸板过的已经炸了，回封的已经确认
2. **对比昨日vs今日涨停分布** — 核心报告维度：各板块涨停数今日vs昨日
3. **关注中军封板状态** — 到11:00还在封的大市值龙头（如京东方A封65亿），比指数涨跌更重要
4. **封板资金大小说明力度** — 下午封单缩减说明撤单，但封着就不算退潮

### 检查输出模板（窗口错过版）

```
📊 盘中快照 | HH:MM

### 🇨🇳 指数现状
{五大指数表格}

### 🔥 今日最大结构变化
{对比昨日的核心发现：新爆发板块/消失板块}

### 🏛️ 板块涨停对比（今日 vs 昨日）
| 板块 | 昨日涨停 | 今日盘中 | 变化 |
|:----|:-------:|:--------:|:----:|

### ⚡ 结论
{仓位建议 + 方向 + 风控}
```
