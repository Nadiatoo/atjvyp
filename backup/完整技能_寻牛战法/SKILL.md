# 寻牛战法 · 四季情绪周期交易体系

> 炒股是自个的马拉松，不逞一时之能，不慕一局之利，以战法为纲，做到心中有尺、进退有据，从而积跬步、至千里。

> 📌 **当前迭代名称：寻牛战法**（简称寻牛）— 顺四季之势，寻龙头之牛。源起庄稼人战法底层原理，经2026年实战验证升级。体系沿革：**庄稼人战法**（底层哲学：情绪周期四季轮换、天时地利人和、因敌变化而作战）→ **彪哥战法**（2022年股帮专栏"短线解盘"的vintage应用版本，含具体买卖规则和案例）→ **寻牛战法**（基于底层原理、针对量化时代独立迭代的当前版本）。**老涂确认**（2026-05-16）：寻牛继承了庄稼人战法的底层"道"（情绪周期、四季框架、天时地利人和），但"术"（具体买卖规则）已根据2025-2026年量化时代的市场生态重新提炼，不受彪哥战法（2022年股帮版本具体规则）的束缚。两者的区别是"根与枝"——根是同一根，但长法不同。实战应用框架详见 references/seasonal-positioning-framework.md。

## 用户交流风格

- **直接给结论**：输出结果时直接给出最终判断，不展示推导过程
- **有错直认**：数据引用错误直接修正，不找理由
- **全面回顾**：当用户问"还记不记得聊了什么"，必须搜索全部近期session做完整汇总，不能只挑当前最新话题回答
- **复盘格式**：表格数据用代码块等宽字体（不产生错位），自然语言用正常markdown写，不死套一种格式。表格需包含前日对比数据。
- **连续重于单日**：任何单日分析必须先回顾全年演进脉络，再落笔。脱离连续背景看单日必然失真。
- **分析必须有框架深度，不只是报数据**（2026-05-18老涂批评）：复盘/盘中分析必须用寻牛框架做五层定位（大盘四季→板块四季→风格四季→预期差评分→策略匹配），用连板梯队+板块阵型+龙头状态说话。单纯罗列指数涨跌、涨停数量、行业分布等于"比用户自己看两分钟收盘信息好一点点"——这是用户原话，不可再犯。框架分析是这技能的核心价值，数据罗列是AI都能做的事。
- **分析结果直接在对话中呈现**，不另存为MD文件。用户不需要去翻文件看结果。如需保存，问过用户再存。
- **自给自足，不把问题抛回给用户**（2026-05-18老涂批评）：遇到数据缺失或工具限制时，先用已有资源解决（Chrome+AppleScript提取东方财富/Tushare Pro/AkShare可用接口），不要问用户"怎么办""你看呢"。用户原话："你还是陷入惯性了。我们的数据源应该够用。只是你依赖我给出方案解决问题。"
- **用已消化的知识，不重新读文件**：全年复盘文件读过并理解后，周期脉络已经存储在 skill 的 references/ 和你的记忆里。做连贯分析时，直接调用已存储的周期分析知识（如 `2026-jan-may-cycle-analysis.md`），而不是重新去读每日复盘原始文件。重新读文件会让分析停留在"逐日罗列"层面，无法体现你对全年脉络的深度理解。老涂要求的"连贯"是建立在已消化知识基础上的融会贯通。

### 🔴 铁律：分析必须有框架深度，不能只报数据

用户纠正原文：*"这个复盘没有一点意义"* 和 *"比我花两分钟看一下收盘信息好一点点，但对于我来说并没有任何价值"*。

**这意味着：**
- 列出指数涨跌、涨停数、行业分布 → 这是数据搬运，不是分析
- 真正的分析必须包含：**大盘四季定位 → 连板/趋势风格判断 → 板块阵型（先锋/中军/后排） → 当前所处的季节阶段 → 次日策略含义**
- 数据是素材，不是结论。框架分析才是价值所在

**每次复盘/盘中分析自检清单：**
1. ✅ 大盘当前处于什么季节？（春播/夏长/秋收/冬藏）
2. ✅ 连板风格和趋势风格分别什么季节？（它们不同步）
3. ✅ 最强板块的阵型如何？（先锋是谁/中军是谁/后排跟风力度）
4. ✅ 当前季节阶段的核心特征有哪些？（用框架量化标准判断）
5. ✅ 候选板块的预期差评分是多少？（位置/变化/资金三维）
6. ✅ 这对明天的操作意味着什么？（仓位/方向/手法/风控）

如果做完分析发现只是把数据重新排列了一遍，那说明还没做到位。

**⚠️ Cron环境数据采集注意事项（2026-05-20发现）：**

**东方财富 API 在 cron 环境可能返回空响应（exit code 52）** — 原因可能是网络/防火墙策略限制。此时用 Sina Finance API 替代获取指数：

```
# ✅ 工作：Sina API（cron环境已验证）
curl -s 'https://hq.sinajs.cn/list=s_sh000001,s_sz399001,s_sz399006,s_sh000016,s_sh000688' \
  -H 'Referer: https://finance.sina.com.cn'

# 返回格式示例：
# var hq_str_s_sh000001="上证指数,4169.5378,38.0102,0.92,6176110,130652248";
# 字段：name, current_price, price_change, change_pct, volume(手), amount
```

**`curl | python3 -c` 会被安全层拦截** — 不能使用管道直接执行。改为两步：
1. 写分析脚本到文件：`write_file(path='/tmp/analyze.py', content='...')`
2. 运行：`terminal('python3 /tmp/analyze.py')`

**Python f-string 花括号与 bash heredoc 冲突** — 在bash heredoc (`<< 'PYEOF'`) 中嵌入带 f-string 的Python代码时，`{var:<10}` 这类对齐格式会被bash花括号展开语法误解析。即使写了heredoc的单引号版本，仍然可能出问题。**最佳实践：** 所有需要长Python代码块的cron任务，直接在 `execute_code` 工具中写（避免shell转义），或写入 `/tmp/` 文件后运行。短命令用 `python3 -c "..."` 但避免使用f-string格式化。

**AkShare `stock_zt_pool_em` 在 cron 环境已验证可用** — `ak.stock_zt_pool_em(date='YYYYMMDD')` 返回完整涨停池（名称、连板数、所属行业、封板资金等），是cron环境下最可靠的分析数据源。

**⚠️ 东方财富 Push API (`push2.eastmoney.com`) — 间歇性可用（2026-05-21实测）**

⏳ **可靠性评估：不稳定（约50%成功率）**。同一日内多次cron执行中，有时正常返回（10:05快照），有时"Remote end closed without connection"（10:25快照）。**不要将东财Push作为主数据源**。优先用AkShare+Sina，东财Push作为可选项尝试。


**关键字段说明：** `f2`=当前价, `f3`=涨跌幅%, `f4`=涨跌点数, `f12`=代码, `f14`=名称, `f62`=资金净流入(元), `f184`=板块涨跌比。

### ⚠️ 数据源与研报生成规范（2026-05-19 老涂重要指导）

#### 1. 知识库是信息的来源之一，不是唯一来源

作为专业分析师，不能只从知识库里找信息。正确的研报生成流程：

```
① 知识库查询 → 看是否有相关题材覆盖
② 网络搜索 → 找最新新闻、公告、行业动态  
③ 财务数据 → Tushare Pro/东方财富拉基本面
④ 行情数据 → 东方财富（实时）/ Tushare Pro（日线）
⑤ 整合 → 多源交叉验证后出结论
```

| **P2** | **baostock** | Tushare挂了时的备用日线 | 免费 🟢备用 |

**不要做的事：**
- ❌ 查不到就说"库里没有" → 去网上搜、去拉Tushare、去翻新闻
- ❌ 只依赖单一数据源 → 交叉验证是基本素养
- ❌ 让老涂给出解决方案 → "你还是陷入惯性了。我们的数据源应该够用。只是你依赖我给出方案解决问题"

#### 2. 复盘报告格式

老涂2026-05-19明确：**"不需要保存为md文件"** 复盘内容直接在对话中说。

正确的复盘呈现方式：
```python
# ✅ 直接说结论
"今天涨停82只，连板分布：首板73，2板5，3板1..."

# ❌ 不要
"复盘已生成 → ~/xxx/复盘_20260518.md"
```

如果是长篇报告，可以在对话中分段呈现关键结论，文件仅作为存档备份。核心价值在于**分析框架**（四季定位、板块阵型、龙头中军），不是数据堆砌。老涂原话："你这个复盘，比我花两分钟看一下收盘信息好一点点，但对于我来说并没有任务价值。"

#### 3. 数据源不稳定时的应对

当某个数据源不稳定时：
- 先用其他可用源（东方财富不行→AkShare→Tushare）
- 用Chrome AppleScript直接从财经网站拉（已验证可行）
- 不要问老涂怎么办 — 他自己解决

**不要什么事都往寻牛框架上套。** 遇到非市场类内容（哲学、认知、方法论文章、读书心得），正确的处理顺序：
1. 先理解内容本身在说什么——就事论事，不翻译成四季语言
2. 内化能内化的部分——哪些拓宽了你的认知？哪些修正了你的思维习惯？
3. 只有当理解了之后自然联想到框架改进，才去考虑对寻牛的进化有什么启示

**不要**：收到内容第一反应是"把它翻译成四季语言"。这样会错过内容本身的深度。
**要**：先当它本身来理解。真正消化了，对框架的启发是水到渠成的事。

### 📚 读书/学习类内容的处理原则

- **读书不是去纠错** — 找到自己不同意的观点然后列出来，是杠精才做的事
- **有用的就吸收** — 对自己思维模式有启发的，记下来内化
- **无用的就跳过** — 不强迫自己从每本书每个章节都找"能用在哪"
- **不套交易框架** — 读书是为了拓展认知维度，不是为了给交易框架找论据。认知提升了，自然会在分析中体现出来
- **学习别人的高质量输出** — 当用户分享优秀的盘前简报或分析文章时，观察它的结构、数据颗粒度、风险意识的呈现方式。目标是"学它的好"，不是"用它验证我的框架"

## 体系总架构（2026-05-16更新）

寻牛体系是一个**内外双源**的分析系统。外部变量（十大类）和内部市场数据两条线并行，互相验证，最终落地到个股。

```
                    ┌─────────────────────────────────────┐
                    │      外部变量监测（小禾每日执行）      │
                    │  十大类 · 识别A类/B类冲击             │
                    └────────────────┬────────────────────┘
                                     ↓ 判断影响方向 + 幅度
                    ┌─────────────────────────────────────┐
                    │      五层四季定位（寻牛核心框架）      │
                    │  ├── 宏观底色四季                     │
                    │  ├── 大盘四季     ← 受外部A类冲击直接影响 │
                    │  ├── 板块四季     ← 也受外部事件直接影响 │
                    │  ├── 风格四季     ← 连板 vs 趋势       │
                    │  └── ⭐预期差评分 ← 三维（位置/变化/资金）│
                    └────────────────┬────────────────────┘
                                     ↓ 交叉验证 → 锁定龙头中军
                    ┌─────────────────────────────────────┐
                    │      策略输出                          │
                    │  仓位 · 方向 · 手法 · 风控             │
                    └────────────────┬────────────────────┘
                                     ↓
                    ┌─────────────────────────────────────┐
                    │      老涂做最终决策                     │
                    └─────────────────────────────────────┘
```

**核心原则：** 外部变量对四季有两条影响路径——同时作用于大盘四季（定总仓位）和板块四季（定方向）。最终所有判断必须落地到个股（板块的龙头和中军），因为交易的是个股，不是指数。

详见 `references/system-framework-v1.md`。完整框架文档还存于桌面：`/Users/tuqibiao/Desktop/寻牛体系_系统框架_V1.md`。

## 适用范围：五大层级（2026-05-12更新：新增风格维度）

四季框架适用于任何时间尺度、任何市场层级，判断逻辑完全一致：

| 层级 | 分析对象 | 四季判定依据 | 备注 |
|------|---------|------------|------|
| 🌍 **宏观底色** | 地缘/货币/通胀 | 地缘冲突走向、央行政策路径、CPI/PPI、关键商品价格 | 定约束条件，不决定买卖点但决定置信度 |
| 🏛️ **大盘** | 上证/深证/创业板/科创 | 指数趋势+量能+涨跌比+连板高度+新高新低 | 定总仓位基调 |
| 📦 **板块/题材** | **概念板块**（禁止用申万行业分类） | 板块位置+涨停数量+龙头状态+催化消息+与大盘共振/背离 | 定方向，板块四季与大盘不同步 |
| 🎨 **风格** | 连板风格 vs 趋势风格 | 连板高度/晋级率、大票vs小票赚钱效应、机构vs游资主导 | 定手法（连板/趋势/混合），独立于大盘和板块四季 |
| 📈 **个股** | 龙头+中军 | 连板先锋7维验证法 / 趋势总龙4维确认法 | 只做与指数共振板块的龙头和中军 |

> **⚠️ 核心认知**：板块的四季不与大盘同步。风格的四季也不与两者同步。2026年5月验证：大盘☀️夏长、趋势风格☀️夏长、但连板风格🌱仍处于低位酝酿——三种不同季节并存。

- **层级铁律（禁止跳级回测）** — 寻牛战法的买卖决策发生在板块+个股层面，不在指数层面。大盘只定总仓位。任何回测必须明确层级：指数级只验证总仓位方向，板块级验证方向选择，个股级验证买卖执行。**跳级验证（如"大盘跌7%买入、涨8%卖出"）信号本身可能有效，但无法执行到实战中**——因为我们交易的永远是板块里的龙头和中军个股，不是上证指数。验证数据：小C用375个板块日线+22个事件验证了板块级四季判定可行，而指数级回测虽能做出统计超额（+27.25% vs 持有+19.27%）但缺乏可执行性。

### 风格四季（待完善——2026-05-12新增维度）

2026年5月实战发现，单纯大盘+板块两层分析不足以描述市场结构。用户提炼出"大为美、硬为美、趋势为美、次新为美、庄为美"——这是对趋势风格☀️夏长高潮的特征刻画。

| 风格类型 | 典型特征 | 主导资金 | 示例周期 |
|---------|---------|---------|---------|
| 🔗 **连板风格** | 小市值<100亿、连板爆发、情绪驱动 | 游资+量化 | 1月商业航天（雷科12板） |
| 📈 **趋势风格** | 大市值500亿+、趋势推进、业绩+逻辑驱动 | 机构+大游资 | 5月科技（寒武纪/中际旭创） |

两种风格各有独立的四季周期，互不同步。2026年1月到5月，连板风格经历了☀️夏长→🍂秋收→🌱低位酝酿至今仍未突破的完整轮回，而趋势风格从4月🌱春播到5月☀️夏长高潮。

**策略含义：确认风格季节后，匹配对应手法。** 连板风格☀️做接力打板，趋势风格☀️做低吸趋势持有。风格错配是手法胜率下降的根源。

### 冰点类型区分（重中之重）

> **核心原则**：四季框架基于市场内生节奏，必须先区分"冲击型冰点"和"内生型冰点"，否则框架会失效。

#### 冲击型冰点（External Shock）
- **特征**：快、急、猛，几天内恐慌一次性释放干净
- **成因**：外部突发事件（政策突变、地缘冲突、流动性危机等）
- **典型案例**：2024年2月初雪球爆仓引发流动性危机、2025年4月贸易战开打大盘两天暴跌
- **性质**：不可预测、不重复、没规律，不具备周期性
- **应对**：只能做事后确认，不能作为四季判断依据

#### 内生型冰点（Endogenous / Market Rhythm）
- **特征**：有酝酿过程，有情绪传导的时间差，有可识别的边际变化节律
- **成因**：市场自身出清—资金面、情绪面、技术面的自然共振
- **性质**：可识别、有规律、可重复，是四季框架的适用土壤
- **应对**：观察成交量萎缩程度、亏钱效应衰竭速度、聪明钱试探性入场信号

> 🎯 **一句话**：冲击型冰点是"强冷空气过境"，寒潮一走市场内生气候该怎么转还怎么转；内生型冰点是"四季轮回中的冬天"。不要把寒潮当成冬天本身。

#### Day 0 板块爆发评估

板块爆发第一天（全部首板）时，用五维框架评估持续性：中军参与度、板块位置、内部结构、大盘共振、催化逻辑。

核心原则：**中军封板是Day 0最强信号**。京东方A封板85亿 > 一堆小票群板。Day 0只做春播窗口判断，真正确认要等Day 1的2板晋级。

详见 `references/day0-eruption-evaluation.md`。

## 四季定义

| 季节 | 情绪状态 | 资金行为特征 | 核心要诀 | 关键细化 |
|------|---------|------------|----------|---------|
| 🌱 **春播** | 恐慌出清→试探→分歧→确认 | 聪明钱先入场，量温和放大 | 无恐慌不开仓；择时（天时）+ 择板块（地利+人和） | **分两步：①撒种子（试探建仓）→②主线确认（等发芽后再加仓）**。原文《主线判断》案例：2021.7.5锂电反弹比稀土快但位置已高，稀土才是真主线。详见 references/zhuangjiren-article-how-to-find-main-line.md |
| ☀️ **夏长** | 共识强化→贪婪扩散 | 放量、龙头带队、赚钱效应扩散 | 持股为主；错过春播则挖掘补涨（位置低+核心属性） |
| 🍂 **秋收** | 狂热→分歧→衰竭 | 高位震荡、补涨齐飞、成交见顶 | 卖在高潮一致；去弱留强节奏：跟风→中后排→核心股 |
| ❄️ **冬藏** | 恐慌出清→麻木→缩量 | 离场、没人敢动 | 观察冬季尾声标志：逆势逞强的板块完成补跌 |

### 春播两步法（2026-05-16修正）

春播不是一步到位，分两个阶段：

**第一步：春播窗口（撒种子）**——看到恐慌出清+低位置板块出现先锋，试探建仓，分仓布局候选，不重仓

**第二步：主线确认（等发芽）**——从候选板块中筛选真主线，加仓

主线确认四特征（原文，2026-05-16 修正版）：

| # | 特征 | 判断标准 | 备注 |
|---|------|---------|------|
| ① | **与大盘共振反弹** | 春播日能有效带动大盘反弹，不只是板块自己涨 | 必要条件 |
| ② | **扛倒春寒** | 遇到大盘倒春寒时表现有韧劲，强于大盘 | **倒春寒不一定发生**。发生了就是最好验证；没发生就跳过，靠③④判断 |
| ③ | **地利人和** | 位置低（地利）+ 产业逻辑好有预期差（人和）——区分真伪的**核心门槛** | 必要条件 |
| ④ | **板块阵型完整** | 先锋进攻（连板开路）+ 中军坐镇（大资金战场）+ 后排补涨（梯队跟进） | 必要条件。无阵型走不远 |

> **误区**：第一个反弹的≠主线（可能是套牢盘自救），第一个共振的≠主线（可能没持续性）。参考案例：2021年7月，锂电池反弹比稀土快但位置已高，稀土才是真主线。

> ⚡ **小周期应用**：四季不止适用于大周期。一个题材从启动到退潮（3-5天）同样经历完整的四季轮回，时间压缩但情绪转化逻辑不变。

### 春播两步法（2026-05-16修正）——撒种子 vs 主线确认

春播不是一步到位。**撒种子（建仓试探）和主线确认（重仓）是两回事。**

**第一步：春播窗口（撒种子）**
- 目标：试探建仓，不确认主线
- 信号：板块低位（距60日线-5%~-15%）、缩量转放量、出现先锋首板、与大盘背离
- 策略：分仓布局几个候选板块，不重仓

**第二步：主线确认（等发芽）**
- 目标：从候选板块中筛选出真主线
- 四特征：①与大盘共振反弹（必要条件）②扛倒春寒（**非必要，不一定发生**，发生了就是最好验证，没发生跳过）③地利人和（位置低+产业逻辑好，**区分真伪的核心门槛**）④板块阵型完整（先锋+中军+后排）
- 满足四特征=真主线=加仓。不满足的即使涨再好也只当反弹处理

> **关键案例：** 2021年7月5日，锂电池反弹比稀土更快，但锂电池是上轮主线位置已高，最终稀土才是真主线（翻倍行情）

### ⭐ 预期差评分系统（2026-05-23新增）

**核心逻辑：所谓主线，就是预期差最大的方向。**

原文四个特征和两个误区，底层都在讲同一件事——市场认知 vs 现实变化之间的偏差。位置低=市场已充分悲观（预期差大），产业逻辑好=现实在变化（预期差有修复动力），扛分歧=聪明钱开始修复预期差，共振=预期差修复被广泛认可。

#### 三维评分标准

| 维度 | 对应要素 | ★★★★★ | ★★★☆☆ | ★☆☆☆☆ |
|------|---------|--------|--------|--------|
| **位置分**（地利） | 板块距60日线位置 | -10%~-20%（低位充分悲观） | -5%~+5%（中位） | +10%+（高位预期差已兑现） |
| **变化分**（人和） | 产业层面真实变化 | 业绩/价格/政策已发生传导 | 传闻/概念/远期故事 | 无任何催化 |
| **资金分**（天时） | 聪明钱介入信号 | 中军封板+板块放量 | 先锋试盘+温和放量 | 无资金信号 |

**综合评分 = (位置分 + 变化分 + 资金分) / 3**

#### 预期差评分在四季中的应用

| 季节 | 预期差状态 | 典型评分 | 策略含义 |
|------|-----------|:--------:|---------|
| ❄️冬藏中段后 | 预期差积累到最大 | ★★★★☆ | 春播窗口候选池开始筛选 |
| 🌱春播窗口（撒种子） | 预期差开始修复 | ★★★★☆ | 分仓布局，≥★★★☆☆可试仓 |
| 🌱主线确认（等发芽） | 预期差修复中段 | ★★★☆☆ | 需四特征验证，评分为辅 |
| ☀️夏长 | 预期差趋于归零 | ★★☆☆☆ | 持股为主，不新开仓 |
| 🍂秋收 | 负向预期差积累 | ★☆☆☆☆ | 只出不进 |

#### 预期差评分在主线判断中的应用

原文四特征中的**特征③（地利人和）** 用预期差评分量化：

```
地利人和条件 = 预期差综合评分 ≥ ★★★☆☆
                             ↓
            位置分(地利) + 变化分(人和) ≥ 6分（两维各满分5）
```

核心原则：
- **预期差大的方向，不一定是主线**，但主线一定出自预期差大的方向
- 2021年稀土案例：锂电位置高（位置分★）、稀土位置低（位置分★★★★★）→ 稀土预期差更大 → 真主线
- 2026年5月元件/PCB案例：冬藏中段无人敢碰（位置分★★★★）、MU涨价+MLCC价格传导（变化分★★★★）→ 预期差大 → 春播种子

### 外部变量双路径（2026-05-16新增）

外部变量同时走两条路径影响市场：
- **A类冲击** → 改变大盘四季轨道（如924政策组合拳：❄️→☀️、关税战：☀️→❄️）
- **特定板块影响** → 直接影响某个板块的四季（如产业政策利好加速板块春播、原油暴涨催化能源板块）

应对原则：同一个事件，两套影响路径分别判断，互不干扰。

### 三大选股要素（天时地利人和）

- **天时**：情绪择时 — 冬藏尾声的恐慌杀跌才是正确春播点
- **地利**：板块位置 — 低（均线附近、无获利盘），无惧大盘扰动
- **人和**：产业逻辑 — 放眼全市场比较，找到预期差最大的方向

### 核心概念

- **反包技能卡**：主线专属。第一次确认后有1次反包护体；强周期可能出现多次，但效力逐级递减
- **补涨铁律**：核心=位置低。主线高潮日=补涨最佳卖点。最核心公司完成加速=板块高潮尾声
- **秋收节奏**：跟风板块→中后排股→核心股，直到核心公司反包技能卡走完
- **仓位管理三原则**：(1)买在分歧卖在一致，小仓位控成本 (2)高景气赛道放宽至5日线清仓 (3)亏损及时止损
- **分仓原则**：不要豪赌单一板块/个股，让复利自然滚动

## 量化时代的影响（重要更新）

2025-2026年市场生态发生显著变化，老战法需做以下调整：

### 1. 季节转换速度加快
量化交易将四季过渡时间压缩了2-3倍。以前的"天"变成"小时"，以前的"渐次退潮"变成"瞬间冰点"

### 2. 反包技能卡：效力递减
第一波反包仍然有效，第二次反包的胜率显著下降

### 3. 多季节并存成为常态
不同板块可能分别处于完全不同的季节位置。选对板块比判断大盘更重要。

### 4. 秋收节奏前置
高潮当天就要开始考虑出货，不等"看到分歧再卖"。

### 5. 冰点的波动率放大
冲击型冰点跌得快反弹也快，内生型冰点跌得慢磨底长。

### 🚨 夏秋过渡混沌识别（边界模糊期）

当大盘同时呈现夏长末段和秋收初段的特征，且无法明确归类于任一时，使用此信号集做交叉判断。

**混沌确认信号集（满足4条及以上=确认混沌过渡期）：**
- [ ] 前2大主线板块同时崩塌（涨停从8+分别降至≤2和0）
- [ ] 唯一增量板块全部为首板（无2板晋级，板块梯队未建立）
- [ ] 总涨停从70-90+区间骤降至~60（降幅30%+）
- [ ] 首板占比 > 80%
- [ ] 行业分布散乱（TOP1板块≤6只，其余行业≤3只）
- [ ] 高标独立行走（先锋涨停但板块内无跟风，板块无人跟随）
- [ ] 指数严重分化（科创/创业板大涨但主板平盘或微跌）

**混沌期核心判断要点：** 不是"市场不行了"，而是"旧主线死了，新主线还没生出来"。此时趋势风格（科创板/半导体/大票）可能仍在夏长，但连板风格已经确认退潮。

**混沌期+隔夜催化 → 破局分析：** 当混沌过渡期遇到重大隔夜催化时，需用三步法判断催化能否打破混沌格局：①催化定位与A股板块映射 ②关键观察点分层（竞价量能→首板晋级→板块扩容）③三种场景推演（突破/高开低走/混沌延续）。详见 `references/catalyst-day-pre-market-analysis.md`。

**混沌期策略含义：**
- 总仓位：轻仓（4-5成），不做重仓
- 方向：聚焦唯一增量板块的持续性（观察次日能否出2板）
- 手法：趋势低吸为主，连板接力观望（连板风格确认退潮）
- 风控：若增量板块次日也退潮（首板全部断板），则全场无主线，可能加速下探
- 关键观察点：①增量板块能否出2板？②总涨停能否回升到70+？③最高标断板后情绪是否快速恶化

**案例参考（2026-05-20）：** 元件8→2、电力8→0同时崩塌；半导体3→6全部首板；总涨停90→61；首板83.6%；高标利仁8板独立但板块无人跟。→ 确认混沌过渡期。

### 概念板块"主场/客场"归属（重要）

一只股票可以同时属于N个概念板块，但在不同板块中的角色完全不同：

| 概念板块 | 角色 | 说明 |
|---------|------|------|
| **主场概念** | 核心角色（先锋/中军） | 逻辑最纯正、市场认可度最高的板块归属 |
| **客场概念** | 边缘成分股 | 虽被分类但非该板块的驱动力 |

**案例：** 中际旭创在光通信/CPO概念中是🏛️核心中军（主场），在国产算力概念中是边缘成分股（客场）。5月12日光通信走强而国产算力退潮，旭创走强=光通信接棒成功，不是"国产算力内部还有票撑着"——因为旭创在国产算力里只是客场身份。

**分析原则：** 对一只股票做板块定位时，先明确它的主场概念。用主场概念做四季判定，避免逻辑混淆。

### ❄️ 冬藏中段（筑底期）识别（2026-05-22实战验证）

#### ⚠️ 数据陷阱：累计跌停 vs 实时跌停（2026-05-22发现）

**场景：午间休市期间获取的跌停数据可能与午后开盘的实时快照存在显著差异。**

2026-05-22 12:30报中根据午间数据报告"跌停从5骤增至19只"，但13:00开盘后AkShare `stock_zt_pool_dtgc_em()` 实时快照仅显示5只跌停。差异原因：

| 数据源 | 含义 | 特点 | 典型场景 |
|:-----:|:----:|:----:|:--------:|
| **午间新闻/中间报道** | 盘中累计值（当日所有曾触及跌停的个股） | 含已反弹的个股，数字偏大 | 财经网站、新闻摘要、盘中预警 |
| **AkShare `stock_zt_pool_dtgc_em()`** | 当前实时快照（此刻仍封跌停的个股） | 不含已打开跌停反弹的个股，数字偏小 | 任何时点的实时数据 |

**实操指引：**
- 报告中明确标注数据来源：`午间累计` vs `实时快照` vs `收盘定稿`
- 冬藏中段判断优先用 **收盘定稿数据**（最终统计），盘中用 **实时快照数据**（当前仍封板）
- 午间到午后数据有差异是正常现象（个股打开跌停反弹），**不要因为数据不一致就怀疑数据源有问题**
- 案例：2026-05-22 12:30报告19只（含盘中曾触及但午后打开反弹的个股），13:00实时快照5只（剩下的才是真正封死的恐慌盘）

**冬藏初段之后不是直接春天，而是进入筑底期。** 恐慌释放完毕后，市场不会立刻恢复——做多力量需要时间集结、板块需要试错、主线需要酝酿。

从初段→中段的过渡标志：

| # | 信号 | 初段特征 | 中段过渡特征 | 含义 |
|---|:---:|:--------:|:-----------:|:----|
| ① | **跌停数量骤降** | 25+只（恐慌抛售） | **2-3只**（利空出清） | 最积极的信号——没人想卖了 |
| ② | **涨停缓慢扩容** | 34只→继续萎缩 | 10→15→20（蜗牛式增加） | 想买的人还没回来，但最差时刻已过 |
| ③ | **高开必低走** | 催化完全被无视 | 高开+0.5%~1%→30分钟内回落80% | 冬藏消化任何利好，内生弱势未改 |
| ④ | **板块效应萌芽** | 零板块效应 | 1个板块出现4-5只涨停（中军参与） | 春播种子出现，但不够确认方向 |
| ⑤ | **首板占比仍高** | >80% | 60-70% | 连板风格仍在❄️，未回暖 |
| ⑥ | **活跃高标存活** | 最高标全断板 | 3-4只2-3板存活（独立于板块） | 高标情绪有韧性，但带不动板块 |

**冬藏中段核心操作原则：**
- 仓位维持**≤3成**。冬藏里不做"抄底"——筑底期不等于见底日
- 冬藏中段通常持续**2-3个交易日**（量化时代压缩至1-2日），需要时间让做多力量集结
- **春播种子出现 ≠ 可以出手** — 一个板块有4-5只涨停+中军参与是🌱春播早期信号，不是买入信号
- 春播确认三条件（需同时满足）：
  ① 板块涨停从4-5只扩容至**8+只**
  ② 中军收盘封住（不炸板）
  ③ 当日指数不跳水回落（收盘价>开盘后20分钟价位）
- 如果不满足，只**跟踪不追高**。历史上筑底期第一天的强势板块往往不是真主线（参考2021年7月：锂电池反弹快但位置高，稀土才是真主线）

**冬藏中段 vs 冬藏初段 对比总结：**

| 维度 | 初段（恐慌期） | 中段（筑底期） |
|:---|:-----------:|:-----------:|
| 情绪 | 恐惧抛售，多杀多 | 麻木观望，无人敢动 |
| 跌停 | 20-30+（批量） | 2-5只（尾声） |
| 涨停 | 30-40只（萎缩中） | 15-25只（缓慢扩容） |
| 催化反应 | 完全无视 | 高开30分钟后消化 |
| 板块效应 | 零 | 1个方向萌芽（4-5只） |
| 策略 | 全面空仓/极轻仓 | 跟踪春播种子，不出手 |

**实战案例：** 2026-05-22验证案例见 `references/2026-05-22-winter-mid-transition-case.md`。三重催化(SMIC+MU+关税退还)下，上证从+0.51%一路回落至+0.10%，元件/PCB板块出现4只涨停（鹏鼎控股中军封23亿），但涨停总数仅15只。符合冬藏中段全部六条信号。

#### ⚠️ 冬藏中段春播种子的"加速分歧"模式（2026-05-22新发现）

**常规情景**：春播种子缓慢扩容（4→6→8只涨停），筑底一般需2-3个交易日。
**异常情景**（本次发现）：春播种子在15分钟内加速+2pp（板块涨幅从+4.38%→+6.35%），中军从1→3只涨停，涨停总数从15→42。

**特征识别：**
| 维度 | 常规情景 | 加速分歧模式 |
|:---|:--------|:-----------|
| 板块涨幅变化 | 缓慢上行或随大盘回落 | 大盘回落时板块**加速**上行 |
| 中军数量变化 | 1只中军 | 1→2→3只中军相继涨停 |
| 涨停扩容速度 | 缓慢（每30分钟+2-3只） | 快速（每15分钟+10只+） |
| 与大盘关系 | 同步或略强 | 严重背离（大盘-0.1% vs 板块+6%） |

**应对原则：** 加速分歧 ≠ 可以追多。冬藏中段板块加速只说明做多资金比预期集结更快，不改变"春播确认需要收盘验证"的铁律。策略调整：
- 允许仓位上限从≤2成提升至≤3成
- 候选跟踪优先级提升
- 但真正的出手点仍需次日确认（收盘不跳水+次日不低开）

详见案例 `references/2026-05-22-winter-mid-transition-case.md` 节2「加速分歧模式」。

#### ⚡ 冬藏中的催化处理（2026-05-22实战补充）

**场景：冬藏初段期间出现明显正向催化（如SMIC中芯北方获批、AMD/NVDA强势财报、产业政策利好发布）**

冬藏的核心特征是内生极弱、利好无法兑现。正向催化在冬藏中不等于做多信号——恰恰相反，它是检验市场强弱的最佳试纸。

**三步判断法：**

| 步骤 | 问题 | 实战应用（SMIC催化案例） |
|:----:|------|------------------------|
| ① 催化定位 | 催化强度够不够改变内生格局？ | SMIC吸收合并中芯北方49%——产业层面中等级别，非924式顶层政策，无跳季能力 |
| ② 竞价验证 | 市场对催化如何响应？ | 高开是肯定的，但需看：竞价涨停是否回升到5+只？半导体板块竞价有无2+只一字/涨停？ |
| ③ 盘面确认 | 催化能否转化为板块效应和持续性？ | 开盘30分钟内半导体涨停能否从0→3+？大盘是否高开低走？量能是否放大？ |

**三种场景：**

| 场景 | 特征 | 应对 |
|:----|:----|:----|
| 🟢 **催化有效** | 竞价涨停5+只、半导体板块3+只涨停、大盘高开不回落、量能放大 | ≤2成轻仓试探半导体/存储方向，不追高，等下午确认 |
| 🟡 **高开低走**（最可能） | 竞价涨停3-5只、半导体2-3只涨停、大盘开盘后回落、量能平平 | 不出手。高开=出货窗口，尊重冬藏框架。等待冲高回落后的企稳信号 |
| 🔴 **催化无效** | 竞价涨停<3只、半导体0-1只涨停、大盘直接低开、价量双缩 | 维持空仓。冬藏深化确认。继续按冬藏策略执行 |

**核心原则（两个铁律）：**
1. **冬藏中不存在"抄底催化"** — 正向催化在冬藏中最多制造一个短反窗口（开盘30分钟），之后回归冬藏节奏。不开新仓，不追高。
2. **催化日反而成了检验冬藏深度的最佳窗口** — 市场对催化反应越冷漠，冬藏越深。SMIC催化如果连30分钟的短反都无法制造，说明冬藏已经超越初段进入深化期。

**盘前评估清单：**
- [ ] 催化级别（A类跳季级 / B类节奏级 / 局部干扰级）
- [ ] 当前大盘冬藏阶段（初段/中段/深段）
- [ ] 竞价涨停能否从前日水平回升
- [ ] 板块竞价力度（同行业涨停数 + 一字板数）
- [ ] 大盘开盘20分钟内量能趋势
- [ ] 结论：催化能否改变冬藏格局 → 除非A类级别，否则不能

### 春播的两步法则（从原文《如何尽早判断出新一轮市场主线》提炼）

春播不是一步到位。撒种子和锁定主线是两回事：

**第一步：春播窗口（撒种子）** — 恐慌出清 + 低位置板块出现先锋首板 → 试探建仓，分仓布局几个候选，不重仓。此时谁是真主线还不知道。

**第二步：主线确认（等发芽）** — 从候选板块中筛选出真主线。原文的四特征：

| # | 特征 | 判断标准 | 备注 |
|---|------|---------|------|
| ① | **与大盘共振反弹** | 春播日能有效带动大盘反弹，不只是板块自己涨（"独乐乐不如众乐乐"） | 必要条件 |
| ② | **扛倒春寒** | 遇到大盘倒春寒时表现得有韧劲，强于大盘，不破关键位 | **倒春寒不一定发生**。发生了就是最好验证；没发生就跳过，靠③④判断 |
| ③ | **地利人和** | 位置低（地利）+ 产业逻辑好、有预期差（人和）——区分真伪的**核心门槛** | 必要条件。没有地利人和，涨得再快也是反弹不是主线 |
| ④ | **板块阵型完整** | 先锋进攻（连板开路）+ 中军坐镇（大资金主战场）+ 后排补涨（梯队跟进） | 必要条件。没有阵型的板块走不远 |

**误区一：** 第一个反弹的板块就是新主线？错。独乐乐不如众乐乐，没有带动大盘共振的板块不是主线。
**误区二：** 第一个和大盘共振的板块就是新主线？错。可能是套牢盘自救的一日游，要看能不能扛分歧、有没有地利人和。

### 板块阵型（原文概念）

原文《如何尽早判断》定义了一个有持续进攻力的板块应具备的完整阵型：

```
先锋（连板开路）→ 扫除前方障碍，提升板块士气，小市值，聚焦全场目光
中军（大资金坐镇）→ 集团军核心，逻辑最纯正+体量最大，大资金主战场
后排（补涨跟进）→ 先锋和中军推进后，带着粮草辎重快速跟随
```

三个角色缺一不可。没有中军的板块一窝蜂高潮后散得快；没有先锋的板块缺乏情绪引领；没有后排的板块没有纵深。

## 每日复盘实战模板（寻牛框架应用）

复盘不是报数据——是**用四季框架解读数据**。老涂原话：「你这个复盘，比我花两分钟看一下收盘信息好一点点，但对我来说并没有任何价值。」

### 复盘的核心逻辑链

```
原始数据（指数/涨停/龙虎榜）
    ↓
用四季框架分类解读 → 大盘四季定位、板块四季、风格四季、连板结构
    ↓
交叉验证 → 当前主线是否清晰？季节是否匹配？
    ↓
输出策略含义 → 仓位、方向、手法
    ↓
明日关键观察点
```

### 每日复盘步骤

**第一步：采集原始数据（5分钟）**
- 大盘指数：东方财富Chrome提取（首页一次拿上证/深证/创业板）
- 涨停池：AkShare `stock_zt_pool_em`
- 龙虎榜：AkShare `stock_lhb_detail_em`

**第二步：框架分析（核心增值环节）**

| 分析维度 | 要回答的问题 | 数据依据 |
|---------|-------------|---------|
| 大盘四季 | 当前处于什么季节？ | 指数趋势+量能+涨跌比 |
| 板块四季 | 哪些板块在春播/夏长？ | 涨停分布+板块效应+龙头高度 |
| 风格四季 | 连板风格还是趋势风格主导？ | 连板高度/晋级率 vs 大票趋势 |

| 主线清晰度 | 有明确主线还是混沌轮动？ | 板块持续性+最高标属性 |

**第三步：输出策略含义**
- 仓位建议（大盘四季定总仓位）

**第四步：明日关键观察点**
- 最高标能否晋级？（决定情绪高度）
- 最强板块有没有持续性？
- 新消息催化方向竞价强度？

### 🔴 收盘复盘（15:30后cron）标准工作流

收盘复盘与盘中分析不同——数据已定格，重点是对比今日vs昨日、验证季节信号、输出四层定位。与 `references/cron-closing-analysis-format.md` 配套使用。

**收盘数据采集顺序（已验证的cron环境工作流，2026-05-21）：**
```
① Sina API → 五大指数收盘数据（上证/深证/创业板/科创50/上证50）
② AkShare → 涨停池 stock_zt_pool_em(date='YYYYMMDD')
③ AkShare → 跌停池 stock_zt_pool_dtgc_em(date='YYYYMMDD')
④ AkShare → 前日涨停池对比（同一API取昨日日期）
⑤ AkShare → 新闻 stock_info_global_em() 查找当日催化事件
⑥ 六信号冬藏核查 → 确认季节跳变
```

**核心步骤说明：**

1. **今日vs昨日对比** — 同时拉今日和昨日涨停池，对比行业分布变化：
```python
df_today = ak.stock_zt_pool_em(date='20260521')
df_yest = ak.stock_zt_pool_em(date='20260520')
t_inds = df_today.iloc[:, 15].value_counts()
y_inds = df_yest.iloc[:, 15].value_counts()
# 重点看：哪个行业大幅减少（退潮）、哪个出现增量（新方向）、首板占比变化
```

2. **冬藏六信号核查** — 收盘后第一条也是最重要的一条分析：用本节上方「❄️ 冬藏初段识别」的六信号集检查当日是否进入冬藏。5/21验证：34涨停+25跌停+增量板块证伪+利好无法兑现 → 冬藏初段确认。

3. **跌停池分析** — `stock_zt_pool_dtgc_em()` 返回含`连续跌停`字段。重点关注：连续跌停天数（如衢州发展4连跌停=极端退潮信号）、行业分布是否集中（行业性暴跌 vs 普跌）、跌停/涨停比。

## 关键陷阱（每次触发必查）

- **模型图片限制**：DeepSeek V4 Flash 不支持图片输入。本地OCR对中文截图效果极差。读图/截图需切换多模态模型。
- **板块分类选择**：禁止使用申万行业分类。市场炒作的是概念板块（商业航天、国产算力等）。统一使用同花顺XBHS.GN概念分类。
- **成交额数据范围**：QVerIS quotation.v1返回单市场数据（000001.SH仅沪市，399001.SZ仅深市）。全市场成交额必须加总沪+深两市数据。
- **成交额必须对比前日数据**：不能用单日绝对值定性。5/12 全市场3.242万亿 vs 5/11的3.539万亿，缩量8.4%。缩量但3.2万亿底座是历史高位——定性要综合看绝对值和前日对比。
- **客户持仓个股分析 ≠ 寻牛战法个股分析**：老涂明确要求。客户持仓分析是专业投顾视角（行业地位/新赛道/催化/研报/财务），不套四季框架。见 references/client-holding-analysis.md。
- **连续重于单日**：任何单日分析必须先回顾全年演进脉络，再落笔。脱离连续背景看单日必然失真。半导体5.11已极致高潮，不能因5.12回调就说还在春播。
- **⚠️ 用已消化的知识，不重新读文件**：全年复盘文件读过并理解后，周期脉络已经存储在 skill 的 references/ 和你的记忆里。做连贯分析时，直接调用已存储的周期分析知识（如 `2026-jan-may-cycle-analysis.md`），而不是重新去读每日复盘原始文件。重新读文件会让分析停留在"逐日罗列"层面，无法体现你对全年脉络的深度理解。老涂要求的"连贯"是建立在已消化知识基础上的融会贯通。
- **🚫 外部分析文章 ≠ 市场本身**（2026-05-14 老涂重要指导）：外部文章（公众号/研报/新闻）是第三方的分析观点，不能直接用寻牛框架去套。正确流程：提取论点→网络搜索第三方权威数据验证/证伪→上市公司基本面交叉验证→市场真实数据看发酵程度和预期差→最后给结论。等这些做完了，如果需要分析该题材在市场中的实际位置，再调用此找牛的四季框架。**复盘文件与外部文章是两种不同性质的输入**：复盘是长期市场感应的记录，学完回市场验证，符合规律的内化到寻牛；外部文章需独立交叉验证后作为信息储备。
- **原文PDF完整性提醒** — 庄稼人战法文件夹内同时有.docx和.pdf版本，docx合并版（11,846字）覆盖了春/夏/秋/冬四篇正文+总纲+案例分享的核心内容，但不包含《如何尽早判断出新一轮市场主线》等独立专栏文章。需要读所有PDF才完整。每次深入分析战法原文前，用 `find 庄稼人战法/ -name "*.pdf"` 确认当前有哪些文件，缺哪篇补哪篇。

- **🔴 盘中分析标准操作流程** — 用户要求盘中分析时：①Chrome拉东方财富实时指数（上证/深证/创业板）②AkShare stock_zt_pool_em取今日涨停连板数据③用寻牛框架做四层分析（大盘→板块→风格→策略）④结论直接对话呈现，不存文件。**盘中分析核心看三点**：连板梯队变化（vs昨日）、板块阵型变化、大盘结构（大小票分化/共振）。**盘中30分钟校验**（10:00/10:15/14:00前后5分钟）按 `references/intraday-mid-session-check.md` 流程执行——验证/修正盘前推论，不重复做完整分析。**盘中核查中军涨停状态**用 `api/qt/stock/get?secid={market}.{code}&fields=f43,f170&fltt=2`（见本skill“东财个股查询API”节）比Chrome更快。
- **连板高度**：注意区分重组一字板和换手连板，前者不代表短线情绪真实强度。
- **🔴 零板块效应 — 无板块集聚的混沌轮动**（2026-05-20发现）：当涨停总数<30只且分布散（如29只跨26行业），这是典型的"无板块效应"混沌结构。特征：①20+涨停找不到2只同行业 ②首板占比>65% ③最高标独立走（带不动板块）④无明显主线。**策略含义：** 这种结构下追板胜率极低，连板风格🌱低位确认。只做趋势风格低吸，不参与连板接力。等板块效应出现（同行业≥3只涨停）再切换模式。
- **复盘是源，框架是流**：框架从复盘中提炼，必须跟随复盘进化。不能用框架去"套"复盘验证对错。新读到复盘的第一优先级是连贯感知趋势是否改变，其次才是反哺框架。
- **半导体季节判断注意**：中芯国际节奏慢半拍，不能用它做板块四季定位的锚。板块内风格分裂可能导致同一板块内连板风格和趋势风格处于不同季节。
- **风格切换注意外部变量**：风格切换不是随机的，由监管政策、地缘冲突、产业逻辑、量化生态等外部变量驱动（详见 references/2026-05-13-style-dimension-research.md）。分析时不能只看市场内部数据，必须同步跟踪这些归因变量。
- **外部变量影响双路径** — 同一个外部事件，可能同时影响大盘四季（定仓位）和特定板块四季（定方向）。必须两套判断并行，不能只看大盘。详见 references/system-framework-v1.md
- **最终落地到个股** — 寻牛战法所有分析的最终目的，是找到值得交易的板块龙头和中军。大盘四季→板块四季→个股，不能停留在任何中间层。判断完美但交易标的选错了=分析无效。

### 第一原则：分清"学"和"用"

收到任何材料，先确定性质再决定处理方式，绝不默认用寻牛框架去套：

| 输入类型 | 特征 | 处理方式 | 与寻牛框架的关系 |
|---------|------|---------|----------------|
| 📚 **认知拓展**（哲学书、认知科学、历史） | 用户说"去读"、"提升认知" | **纯学习**：理解、内化、不分析 | 不强制关联。自然消化后如有共鸣再回溯，没有就放着 |
| 📄 **方法学习**（他人的分析文章、复盘、框架、研报） | 用户发PDF/文档，没有说"帮我分析"时 | **系统研读+存知识库**：先理解作者的思维框架和逻辑链条 | 不翻译成寻牛语言。先理解他本身怎么想的，消化后再看有无补充战法的地方 |
| 📊 **市场分析**（需要你判断行情/板块/个股） | 用户说"分析一下"、"你怎么看" | **用寻牛框架**：四季定位、板块阵型、策略建议 | 这是框架的主战场，放心用 |

### ⚠️ 我常犯的错误（反复犯，必须读）

**收到任何输入 → 自动用寻牛框架去解释。** 这是系统1的惯性——熟悉的东西最省力。寻牛是我最熟悉的框架，所以大脑自动优先用它来理解任何信息。

**代价**：当你用已有框架去套新内容时，你只是在确认已知，不是在拓展未知。真正有价值的东西恰恰是框架之外的东西。

**典型错误场景（2026-05-18）：** 在写盘前分析时收到野村存储研报PDF，第一反应不是读完理解、存到知识库，而是"这个内容能用在我当前的盘前分析里"。结果把学习材料当论据来用。老涂纠正："发你的报告不用强套啊。这是给你学习的资料。充实你的大脑。"

**纠正方法：**
1. 收到材料后，强制先做"清空预设"——问自己"这个材料是来学什么的"，而不是"这个能对应到寻牛的什么"
2. **如果在做分析任务时收到学习材料，先存到待读清单，分析做完再消化，不要混在一起处理**
3. 学习材料解读完成后，另存到 references/ 下作为知识储备

### 事件冲击四级分类（2026-05-16 经数据验证）
基于375个板块日线数据 + 22个历史事件（2024-2026）的标注分析，事件对市场的影响可分为四级。阈值经多版本回测对比，推荐中等阈值（40/20/8）：
```
级别                    跳变阈值    案例数    实战含义
🔴 全局跳变级           >40%        17       重新评估大盘和板块四季，调整总仓位
🟠 结构性冲击级        20-40%       4       大盘方向不变，但受影响板块换仓操作
🟡 节奏影响级           8-20%       0       不改变四季定位，仅调整仓位权重
🟢 局部干扰级           <8%         1       不动作，保持观察
```
**使用基准日期规则**：重大事件的影响窗口要用「事件前5交易日 + 事件后15交易日」计算跳变，不能从事件当天开始算（924验证：用事件当天基准仅35.8%跳变，用事件前5日基准跳变率达98.9%）。

**二维分级矩阵**（经924数据验证：单用跳变率会低估趋势加速型事件）：
```
                   高涨跌幅               低涨跌幅
高跳变率          全局趋势逆转            全局噪音跳变
低跳变率          趋势加速（924在此）     局部干扰
```
924是典型"低跳变+高涨幅=趋势加速"——它之前市场已在夏长初期，事件加速到夏长中期，季节没跳但趋势被强化。详见 references/system-framework-v1.md 的「事件冲击」章节。

特征：顶层政策突变、重大地缘事件、系统性金融风险。大盘和/或板块直接跳过当前季节进入下一个季节。

**应对流程：** 确认事件 → 判断影响方向（利好/利空） → 重新评估大盘四季（可能跳季） → 判断受影响最大的板块（也跳季） → 输出修正后仓位+方向

**历史案例：**
- 924政策组合拳：大盘❄️冬藏→☀️夏长，金融/地产/消费板块同步跳季
- 关税战开打：大盘☀️夏长→❄️冬藏
- 半导体国产化政策落地：大盘无影响，半导体板块从冬藏直接到春播

### B类冲击 — 影响四季节奏

特征：经济数据波动、行业政策调整、情绪自然起落。不改变四季方向但影响节奏。

**应对流程：** 确认事件 → 判断对当前四季是加速还是减速 → 调整仓位权重（±10-20%）→ 不改变四季定位

**历史案例：**
- 美债收益率飙升 → 回调2天，不改大盘方向但科技成长板块秋收提前
- CPI数据高于预期 → 通胀担忧短期升温，不改大盘方向
