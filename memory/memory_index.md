## 四、用户重要要求记录

### 🎯 根本原则（必须每次遵守）

#### 1. 结果导向原则
- **要求**：只关心结果，按时交付高质量分析报告
- **禁止**：需要用户参与过程，输出思考过程
- **落实**：系统完全自动化，直接给最终答案

#### 2. 专业标准原则
- **要求**：真实数据，具体分析，战法应用
- **禁止**：模拟数据，假大空分析，泛泛而谈
- **落实**：验证数据源，提高分析深度，应用战法逻辑

#### 3. 系统可靠原则
- **要求**：完全自动化，主动监控，自我修复
- **禁止**：需要人工触发，等待用户提醒，依赖人工修复
- **落实**：修复权限配置，建立监控机制，实现自动修复

### 📝 具体工作要求

#### 分析报告要求：
- **必须包含**：具体龙头股、中军股识别和分析
- **必须基于**：当日真实市场数据
- **必须提供**：具体操作策略和风险控制
- **禁止行为**：使用模拟数据、假大空分析、模糊表述

#### 系统运行要求：
- **定时任务**：工作日08:00盘前分析，17:00盘后分析
- **自动执行**：任务自动触发，自动执行，自动推送
- **状态监控**：主动监控任务执行状态，自动发现问题
- **故障恢复**：自动修复或告警，不需要用户干预

#### 交流互动要求：
- **直接给答案**：直接给出具体股票和操作建议
- **应用战法**：基于彪哥战法逻辑进行分析
- **简洁明确**：不绕弯子，不保留，不模糊
