## 🧠 核心认知框架：系统化多维分析（2026-03-25升级）

### 基础框架：拓扑思维
- **市场理解**：市场是高维拓扑流形，状态在流形上连续运动
- **分析方法**：连通性分析、奇点识别、反馈循环分析、动态演化分析

### 新增分析框架（2026-03-25）
1. **地缘传导五层框架**：
   - 情绪冲击 → 资金流动 → 产业链重构 → 政策应对 → 长期格局

2. **市场四季切换框架**：
   - 数据+情绪+资金+技术四维判断
   - 春生、夏长、秋收、冬藏动态识别

3. **三层分析思维**：
   - 事件层（What）→ 逻辑层（Why）→ 系统层（How）

4. **彪哥战法多维框架**：
   - 基本面+技术面+资金面+情绪面综合
   - **龙头股定义**：市场情绪风向标，具备高弹性、高关注度、带动板块效应的个股
     - 特征：连板高度、成交量放大、市场关注度最高
     - 作用：引领板块行情，决定市场情绪走向
     - 示例：连板龙头、趋势龙头、题材龙头
   - **中军股定义**：板块基本面核心，具备稳定性、流动性、机构认可度的个股
     - 特征：市值较大、基本面扎实、机构持仓集中
     - 作用：稳定板块军心，提供流动性支持
     - 示例：行业龙头、权重股、机构重仓股
   - **关系**：龙头打高度，中军稳军心，两者相辅相成
   - **分析方法**：信息感知 → 预期差发现 → 机会识别 → 持续进化
     - **信息感知维度**：事件、逻辑、情绪、资金、数据
     - **预期差发现**：市场认知 vs 现实变化对比
     - **机会识别**：龙头最先反映变化，中军基本面最受益
     - **持续进化**：系统反馈，认知升级，框架优化

### 思维原则升级
- **从线性到系统**：关注要素相互作用
- **从静态到动态**：考虑时间维度变化
- **从单维到多维**：综合多个角度分析
- **从反应到预见**：提前预测而非事后解释
- **从数据分析到信息感知**：全面感知事件、逻辑、情绪、资金等多维度信息
- **从框架限制到思维开放**：保持创造性思考，不机械匹配
- **从零散判断到系统框架**：建立可复制、可验证、可持续的分析系统
- **从数据不完整到数据优先**：系统功能必须在数据完整的基础上建设（2026-03-30新增）
- **从快速推进到渐进完善**：从核心功能开始，逐步验证和完善（2026-03-30新增）
- **从假设驱动到验证驱动**：每个功能都要有验证机制（2026-03-30新增）
- **从答案给出到能力建立**：培养发现机会的能力，而非给出具体答案
- **从二元对立到系统协同**：多个能力可以协同工作，不是非此即彼
- **从结果反推到过程分析**：分析过程、时间、性质，不能简单从结果推断原因
- **从确认偏误到反向验证**：强制反向思考，寻找 contradictory 证据
- **从单一能力到能力系统**：投资能力是机会发现、错误避免、协同决策的系统组合
- **从假大空分析到市场验证**：所有分析最终需要市场资金验证，高辨识度=市场共识=资金用钱投票（2026-03-31新增）
