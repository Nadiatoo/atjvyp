# 持仓分析系统 (Position Analysis System)

基于三层架构的客户持仓分析工具，为证券投资顾问提供专业的持仓结构分析和行业轮动分析。

## 🎯 核心功能

### 基础层：数据导入与清洗
- 支持Excel/CSV格式的持仓数据导入
- 支持手动录入持仓信息
- 数据验证与标准化处理
- 实时行情数据获取（东方财富API）

### 分析层：多维度智能分析
1. **持仓结构分析**
   - 行业分布比例分析
   - 个股集中度分析
   - 仓位比例分析
   - 行业偏离度分析（vs 沪深300）

2. **行业轮动分析**
   - 历史行业配置变化趋势
   - 行业动量/反转效应分析
   - 板块轮动节奏识别
   - 行业轮动建议

3. **风险评估**
   - 行业集中度风险评估
   - 相关性矩阵分析
   - 压力测试（行业下跌场景）
   - 风险预警机制

### 应用层：实用功能模块
- **风险预警**：仓位超限、集中度风险提醒
- **调仓建议**：再平衡策略、止损止盈建议
- **报告生成**：日报、周报、月报自动生成
- **可视化展示**：图表自动生成（饼图、趋势图、热力图）

## 🚀 快速开始

### 安装依赖
```bash
pip install pandas openpyxl matplotlib plotly jinja2 requests
```

### 运行分析
```bash
cd position_analysis/src
python main.py --input ../data/sample_portfolio.xlsx --output ../outputs/report_20260416.md
```

### 主要参数
- `--input`: 输入文件路径（Excel/CSV）
- `--output`: 输出报告路径
- `--date`: 分析日期（默认今天）
- `--client`: 客户姓名
- `--format`: 输出格式（markdown/html/pdf）

## 📊 数据格式要求

### Excel文件格式示例
```
股票代码 | 股票名称 | 持仓数量 | 成本价 | 行业分类
--------|----------|----------|--------|---------
000001 | 平安银行 | 1000     | 15.20  | 银行
600036 | 招商银行 | 800      | 32.50  | 银行
000858 | 五粮液   | 500      | 180.30 | 食品饮料
```

### 必填字段
1. **股票代码**：6位A股代码
2. **股票名称**：股票中文名称
3. **持仓数量**：整数，单位：股
4. **成本价**：浮点数，单位：元/股

### 可选字段
- 行业分类（如为空，自动从申万行业分类匹配）
- 买入日期
- 备注信息

## 🔧 配置说明

### 行业分类标准
- 默认使用申万一级行业分类（28个行业）
- 支持自定义行业分类映射
- 自动匹配股票代码到行业

### 行情数据源
1. 东方财富API（实时A股数据，主数据源）
2. QVeris API（备用数据源，全球市场）
3. 本地缓存机制（减少API调用）

### 报告模板
- 支持Markdown格式（默认）
- 支持HTML格式（带图表）
- 支持PDF格式（需安装wkhtmltopdf）

## 📈 分析指标

### 结构分析指标
1. **行业分布比例**：各行业市值占总市值比例
2. **前十大持仓集中度**：前十大持仓市值占比
3. **行业偏离度**：相对沪深300的行业配置偏离
4. **仓位集中度**：赫芬达尔-赫希曼指数（HHI）

### 轮动分析指标
1. **行业动量**：各行业近期收益率
2. **轮动强度**：行业配置变化幅度
3. **轮动方向**：增配/减配行业识别
4. **轮动节奏**：历史轮动周期分析

### 风险评估指标
1. **行业集中度风险**：单一行业最大暴露
2. **相关性风险**：行业间相关性矩阵
3. **压力测试损失**：极端场景下最大回撤
4. **风险价值（VaR）**：95%置信度下的最大损失

## 🎨 输出示例

### 文本报告包含
1. **封面信息**：客户信息、分析日期、分析人员
2. **摘要部分**：核心结论与建议
3. **详细分析**：结构分析、轮动分析、风险评估
4. **投资建议**：具体操作建议与风险提示
5. **附录**：详细数据表格、图表说明

### 图表输出
1. **行业分布饼图**：当前持仓行业分布
2. **行业配置趋势图**：历史行业配置变化
3. **行业收益贡献图**：各行业收益贡献度
4. **风险热力图**：行业相关性热力图
