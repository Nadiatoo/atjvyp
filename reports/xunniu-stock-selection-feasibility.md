# 寻牛战法选股系统 — 可行性分析

> 2026-05-15 | 小C

## 一、结论先行

**完全可行。** 寻牛战法的核心规则足够清晰、可量化，数据源和回测基础设施已有，可以构建一套「半自动」选股系统——机器做筛选和信号生成，人做最终决策。

预计从零到可用的 MVP 需要 **2-3 周**，完整版约 **6-8 周**。

## 三、可自动化 → 不可自动化的分层

### 第一层：数据采集（100% 自动化）

```
全市场实时行情 → 涨停板池 → 连板高度 → 板块排名 → 成交额 → 北向资金
```

- 已有 `data_pipeline.py` 覆盖
- 只需加一个涨停板数据源（东方财富已有接口）

### 第二层：季节判定（95% 自动化）

| 判定项 | 数据源 | 规则 |
|--------|--------|------|
| 大盘四季 | 涨跌停数 + 涨跌比 + 上证涨跌幅 | 规则引擎已实现 |
| 板块四季 | 板块涨停数 + 龙头状态 + 共振/背离 | 可量化 |
| 风格四季 | 连板高度 + 晋级率 + 大票vs小票 | 可量化 |
| 冰点类型 | — | **需人工** |

### 第三层：个股筛选（80% 自动化）

**连板先锋 7 维验证**：

| 维度 | 自动化程度 | 实现方式 |
|------|:--:|------|
| ① 爆发日时间优先 | ✅ | 涨停时间排序 |
| ② 2板试金石 | ✅ | 连板数≥2 过滤 |
| ③ 分歧抗跌 | ✅ | 板块分歧日跌幅排序 |
| ④ 反包能力 | ✅ | 断板后2-3日涨跌幅 |
| ⑤ 换手健康 | ✅ | 10%-30% 区间过滤 |
| ⑥ 市值适中 | ✅ | 50-300亿过滤 |
| ⑦ 带动性 | ✅ | 同板块涨停数统计 |

**趋势总龙 4 维确认**：

| 维度 | 自动化程度 | 实现方式 |
|------|:--:|------|
| ① 贯穿周期创新高 | ✅ | 新高标记 + 板块周期匹配 |
| ② 不连板趋势推进 | ✅ | 涨幅模式识别 |
| ③ 不破5日线 | ✅ | MA5 与收盘价比较 |
| ④ 成交额前列 | ✅ | 全市场成交额排序 |

### 第四层：策略匹配（70% 自动化）

```
大盘季节 → 仓位建议
板块季节 → 方向选择
风格季节 → 手法匹配（连板/趋势/混合）
```

规则清晰可编码，但**最终仓位由人决定**。

### 第五层：最终决策（0% 自动化 — 必须人做）

- 宏观底色判断（地缘/货币/政策）
- 预期差评估
- 止损止盈设置
- 仓位大小

## 七、风险与局限

1. **量化时代的四季加速**：战法已识别到量化压缩了 2-3 倍时间，系统需要高频数据（分钟级）才能真正捕捉转换点。日线级别可能滞后。

2. **冰点分类依赖上下文**：冲击型 vs 内生型冰点的区分需要外部事件知识，纯数据驱动无法做到。这是最大的自动化盲区。

3. **板块概念分类更新**：市场炒作的概念板块不断变化（从申万到 XBHS.GN），需要动态维护板块映射。

4. **过度拟合风险**：5年回测验证产生 91% 成功率，但 2021-2026 这个区间刚好包含一轮完整牛熊，样本量有限。

5. **数据源稳定性**：akshare 偶发接口变更，腾讯HTTP 免费但不保证 SLA。生产环境需要多源冗余。

## 八、MVP 建议（2周可交付）

第一版只做一件事：**每日盘后自动输出候选池 + 信号简报**。

输入：当日收盘数据
输出：
- 大盘/板块/风格四季判定
- 龙头候选 TOP10（含7维评分明细）
- 中军候选 TOP5（含4维评分明细）
- 春播/夏长信号提示
- 风险预警（跌停激增、连板断层等）

不需要人工干预的部分全部自动完成，需要人工的部分（宏观底色、最终决策）留给小禾。
